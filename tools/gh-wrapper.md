# GitHub CLI Wrapper

A deterministic tool wrapping the GitHub CLI (gh).

## Commands

- `gh issue list` - List issues
- `gh pr create` - Create pull request
- `gh pr view` - View pull request details

## Requirements

Requires `gh` CLI to be installed and authenticated.
