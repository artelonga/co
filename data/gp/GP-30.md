AS A developer creating new game universes,
I NEED a separate repo with plugin templates and all 5 existing games packaged as plugins,
SO THAT I can fork a template, define my universe, and register it with the base app without modifying core code.

## Scope
- New `universes/` repo with one directory per plugin
- `template/` — starter plugin with minimal `plugin.toml`, example tile map, README
- 5 existing games extracted as plugins: tetris, snake, invaders, pointset, poker
- Each plugin has: `plugin.toml`, `universe.json` (tile/theme data), optional `src/` for custom logic
- README documenting how to create a new plugin

## Architecture
```
universes/
├── README.md               # How to create a plugin
├── template/               # Starter template
│   ├── plugin.toml
│   ├── universe.json
│   └── README.md
├── tetris/
│   ├── plugin.toml
│   └── universe.json
├── snake/
├── invaders/
├── pointset/
└── poker/
```
