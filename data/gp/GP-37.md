GIVEN the GP project has 35+ tasks with parent/child relationships and priorities,
WHEN `co auto` needs to pick the next task,
THEN:
- [ ] Reads all task files from the specified space (default: current space)
- [ ] Filters to `status: todo` only
- [ ] Resolves dependency order: parent tasks before children (topological sort on `parent` field)
- [ ] Within same dependency level, sorts by priority: critical > high > medium > low
- [ ] Skips tasks whose parent is not `done` (blocked)
- [ ] Returns the single highest-priority unblocked task
- [ ] `--task GP-N` flag overrides auto-selection with explicit task
- [ ] `--dry-run` shows selected task without executing
- [ ] commit: `feat(cli): task selector with dependency-aware priority ordering`
