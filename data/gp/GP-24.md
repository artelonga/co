AS A creative user,
I NEED to create custom universes with tile maps, themes, rules, and portals,
SO THAT I can build my own worlds, share them publicly, and link them to other universes via portals.

## Scope
- Universe CRUD (create, read, update, delete) via API
- TOML manifest + JSON tile data as definition format
- Tile map editor in the web UI (canvas-based grid editor)
- Universe viewer (canvas renderer with theme colors)
- Theme system (color palettes for walls, portals, entities, background)
- Personal universe auto-created on registration
- Public universe browsing / discovery

## Plugin Architecture
- Each existing game (Tetris, Snake, etc.) packaged as a plugin in `universes/` repo
- `plugin.toml` manifest defines: name, version, universe config, custom routes
- Plugin template provided for creating new universes
