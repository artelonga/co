GIVEN the review phase has passed,
WHEN the task is completed,
THEN:
- [ ] Task frontmatter `status` updated from `todo` to `done`
- [ ] `updated_at` timestamp set to current time
- [ ] If task has a `commit` field, uses that as the commit message prefix
- [ ] Otherwise generates conventional commit: `feat({label}): {title}` or `fix({label}): {title}`
- [ ] Git operations: `git add`, `git commit` with the conventional message
- [ ] Semver: if epic defines a version milestone, logs it for release tagging
- [ ] Prints summary: task title, time taken, criteria passed
- [ ] commit: `feat(cli): task completion with conventional commit`
