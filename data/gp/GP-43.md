GIVEN `co auto` executes with `--dangerously-skip-permissions` and modifies code/files,
WHEN we run the automation pipeline,
THEN we need a dedicated, isolated test environment:

## Port Assignments (all localhost-only by default)

| Port | Service | Binding | Notes |
|------|---------|---------|-------|
| 8742 | Game Server (Rust/Axum) | 127.0.0.1 | Game API — stats, wallet, leaderboards |
| 8743 | Tasks Service (co-web) | 127.0.0.1 | Task/notes API — projects, CRUD |
| 8744 | Universe Service (future) | 127.0.0.1 | Reserved for universe API |
| 5173 | SvelteKit Dev Server | 127.0.0.1 | Frontend dev mode (Vite HMR) |
| 4173 | SvelteKit Preview | 127.0.0.1 | Production build preview |
| 5432 | PostgreSQL (future) | 127.0.0.1 | Reserved for production DB migration |
| 6379 | Redis (future) | 127.0.0.1 | Reserved for multiplayer pub/sub |

## Safety Measures

- [ ] All services bind to `127.0.0.1` only (no `0.0.0.0` binding)
- [ ] Test database at separate path: `~/.local/share/game-test/game.db` (env: `GAME_DB_PATH`)
- [ ] `JWT_SECRET` set to a test-only value (env file: `.env.test`)
- [ ] Git worktree used for `co auto` execution (isolated from main branch)
- [ ] `--dangerously-skip-permissions` only in the worktree, never on main
- [ ] co auto log output captured to `~/.co/runs/` for audit
- [ ] Max timeout per task: 10 minutes (configurable, prevents runaway)
- [ ] `.env.test` file with all service configuration:

```bash
# .env.test — dedicated test environment
GAME_SERVER_PORT=8742
TASKS_SERVICE_PORT=8743
UNIVERSE_SERVICE_PORT=8744
GAME_DB_PATH=~/.local/share/game-test/game.db
JWT_SECRET=test-secret-do-not-use-in-production
RUST_LOG=info
```

## Startup Script

```bash
#!/bin/bash
# start-test-env.sh
set -e
source .env.test

echo "Starting test environment..."
cargo build --features server --bin game-server
./target/debug/game-server &
echo "Game server: http://127.0.0.1:$GAME_SERVER_PORT"

cd $CO_WORKSPACE
cargo run --bin co-web -- --port $TASKS_SERVICE_PORT &
echo "Tasks service: http://127.0.0.1:$TASKS_SERVICE_PORT"

cd $GAME_REPO/web
npm run dev -- --port 5173 &
echo "SvelteKit: http://127.0.0.1:5173"

echo "All services running. Press Ctrl+C to stop."
wait
```
