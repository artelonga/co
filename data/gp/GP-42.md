GIVEN individual tasks can be executed and reviewed,
WHEN `co auto --cycle` is invoked,
THEN:
- [ ] Runs the full pipeline (select → context → execute → review → commit) in a loop
- [ ] After each task completion, selects the next unblocked task automatically
- [ ] Stops on: all tasks done, a task fails review twice, `--max-tasks N` limit reached
- [ ] Between tasks, prints summary and waits 3 seconds (configurable `--delay`)
- [ ] `--max-tasks` flag limits how many tasks to process (default: unlimited)
- [ ] `--stop-on-fail` flag stops the loop on first review failure (default: true)
- [ ] Run tracker: `~/.co/runs/auto_{space}_{timestamp}.yaml` logs all tasks processed
- [ ] Final summary: tasks completed, tasks failed, total time, version progress
- [ ] commit: `feat(cli): auto-cycle loop for continuous task execution`
