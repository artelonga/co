AS A developer working through the GP roadmap,
I NEED a `co auto` command that picks the next task, executes it via Claude Code with full context injection, reviews against acceptance criteria, and cycles to the next task,
SO THAT the entire roadmap can be executed incrementally with automated validation at each step.

## Architecture (modeled after PST auto)

```
co auto [--space gp] [--task GP-2] [--dry-run]

Pipeline per task:
1. SELECT  → pick next todo task (priority + dependency order)
2. CONTEXT → inject: task body, acceptance criteria, CLAUDE.md, project context
3. EXECUTE → launch claude -p <prompt> --dangerously-skip-permissions
4. REVIEW  → check acceptance criteria (checklist items) against work done
5. COMMIT  → conventional commit with semver from task metadata
6. UPDATE  → mark task done, cycle to next
```

## Context Injection Layers (from PST pattern)
1. **Base layer**: CLAUDE.md conventions (commit format, TDD, cargo test/clippy/fmt)
2. **Task layer**: Full task markdown (GIVEN/WHEN/THEN + acceptance criteria checklist)
3. **Project layer**: project.yaml + epic context (parent task body)
4. **Repo layer**: Cargo.toml, directory structure, existing code patterns
5. **Review layer**: Previous task's review output (if failed, feeds back)
