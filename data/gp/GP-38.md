GIVEN a selected task needs full context for Claude Code execution,
WHEN the context builder assembles the prompt,
THEN:
- [ ] Base layer: reads CLAUDE.md from workspace root and injects as system context
- [ ] Task layer: reads full task markdown (frontmatter + body with GIVEN/WHEN/THEN)
- [ ] Epic layer: if task has `parent`, reads parent epic markdown and prepends
- [ ] Project layer: reads project.yaml for project name, key, description
- [ ] Repo layer: reads Cargo.toml (or package.json) for dependency context
- [ ] Review layer: if previous task review failed, injects review report as feedback
- [ ] Layers separated by `---` delimiters (PST pattern)
- [ ] Final prompt format: "Execute this task. Follow acceptance criteria exactly.\n\n{layers}"
