## CO-542 — dev tasks now sort numerically (CO-2 before CO-10)

The dev-task board/table listed tickets lexically (CO-1, CO-10, CO-100,
CO-11, …) instead of numerically. Fixed in the backend: `list_dev_tasks`
now orders results by the trailing integer of the `CO-N` key, so the board
and table render in true numeric order regardless of how the frontend
assigns row ids.

### Why
The list came straight from `query_by_path_prefix`'s `ORDER BY path ASC`
(lexical), and the frontend assigns a djb2-hash id per row, so neither layer
could sort by CO-N. Sorting at the source (parsing the int after `CO-`) keeps
the fix in one place; keys without a numeric tail sort last, stably.
