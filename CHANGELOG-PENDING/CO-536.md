## CO-536 — Content-agnostic self-host smoke (smoke-selfhost.sh)

`scripts/smoke-selfhost.sh` is the self-host / single-box replacement for the
estate-pinned `smoke-prod.sh`: it proves platform *capabilities*, not seed
content, so it works on a prod that serves zero universes or a hundred.

- **No hard-coded seed counts, tenant/universe names, or managed URLs.** Defaults
  to `http://localhost:8742` (override via `[BASE_URL]` arg or `$BASE_URL`).
- Checks: `GET /api/health` → `status: ok` **and** version equal to the workspace
  version parsed from `Cargo.toml`; a clean serve-allowlist via the CO-439
  `audit_serve` bin against the local data dir; and — only when admin creds are
  provided via `CO_SMOKE_EMAIL`/`CO_SMOKE_PASSWORD` — a fully self-cleaning
  capability round-trip (password-login → create an ephemeral random-key universe
  → add an entry → GET it back → delete the universe). Without creds the round-trip
  is skipped with a note and the read-only invariants still gate.
- Coloured `✓`/`✗` PASS/FAIL lines (reuses `smoke-lib.sh`); exits non-zero on any
  failed invariant. An EXIT trap always deletes the ephemeral universe.
