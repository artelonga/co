## CO-555 — Ingest the translator /en mirror as language-tagged entries

The modular translator (`scripts/i18n/translate.py`, pt→en bound to
`CO_I18N_MODEL_PT_EN=qwen2.5-coder:14b`) renders a slug-parallel `<out>/en/...`
markdown mirror. CO now **ingests that mirror** as separate, language-tagged
entries at `en/<slug>` (frontmatter `language: en`) so `/sobre` ↔ `/en/sobre` is
a clean twin switch — no content fork.

- **`translate::ingest`** (new, reusable):
  - `ingest_language_pages(repo, universe_root, key, lang, pages)` — the atomic
    entry. For each page: force `language: <lang>`, target path `<lang>/<rel>`,
    write the file, **run `co::validate::validate_file`**, and only then index.
  - `ingest_mirror_dir(...)` — thin filesystem walker that consumes the
    translator output directory (`<out>/<lang>`) directly.
  - **Idempotent**: keyed by body hash against the existing entry — a re-run with
    an unchanged mirror is a pure no-op (`unchanged`); a changed body `updated`s.
  - **Validated before ingest**: an error-severity issue removes the file and
    skips indexing (reported), so a bad translation never poisons the index.
  - **Writes through the vault + `SqliteEntryRepository`, never raw SQLite** —
    correct for the sharded per-universe DBs (`universes/{ab}/{cd}/{key}/data.db`).
- **Boot wiring**: `Storage::reseed_template_en_pages()` ingests the committed
  English mirror of the intro pages (`seed/template/en/{index,sobre}.md`,
  embedded via `include_str!`) on every boot. These are NEW paths (`en/…`), so
  the existing `include_str!` reseed of `index.md`/`content/*.md` never clobbers
  them (confirmed).

### Why
An English surface without a forked content tree: the pt markdown stays
canonical, the en entries are a generated/ingested artifact. Template-as-software
holds — the ingest is content-agnostic tooling; the mirror is a runtime artifact.

### Corner cut
The two seeded `en/*.md` mirrors are hand-translated stand-ins committed as the
translator artifact (the live LLM path needs Ollama, unavailable in CI). Re-run
`scripts/i18n/translate.py --to en` to regenerate; `ingest_mirror_dir` consumes
its output as-is.
