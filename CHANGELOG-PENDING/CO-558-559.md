## CO-558 / CO-559 — one changelog surface + sidebar "Gestão" (not "Tools")

**CO-559 (Tools mislabel).** The sidebar section that lists admin actions
(Deployments) was titled "Ferramentas"/"Tools", but those are not tools. Renamed
the `sidebar.section.tools` label to **Gestão** (pt) / **Management** (en) in the
shared i18n dictionaries (key kept). "Ferramentas"/"Tools" is now reserved for the
future CO-503 on-demand tools surface.

**CO-558 (one changelog, not two).** The changelog previously appeared in three
places: the board Histórico view-tab, a standalone `/changelog` page, and a
"Changelog" entry in the sidebar list. Consolidated to a single surface — the
board Histórico tab:

- Removed the redundant "Changelog" entry from the sidebar Gestão list, so it now
  holds only Deployments.
- The standalone `/changelog` route now redirects to the board changelog tab
  (`/?view=changelog`) instead of rendering a second changelog viewer.
- Added `?view=<board-view>` deep-linking so the redirect lands on the Histórico
  tab (initial view read from the URL; active tab synced at boot).
