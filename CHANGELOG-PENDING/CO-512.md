## CO-512 — configurable bind host (safe local default)

co-web now resolves its TCP bind host instead of always binding `0.0.0.0`.

A new `CO_WEB_HOST` env var / `--web-host` flag sets the bind address
explicitly. When it is unset, the host is derived from `CO_ENV`:

- `CO_ENV=local` -> binds `127.0.0.1` (loopback only) so a local dev server is
  no longer reachable from the LAN by default;
- any other env (`prod`, `uat`, `test`, `staging`, unset, ...) -> binds
  `0.0.0.0`, preserving the previous behaviour so Fly/prod and any network
  deploy keep working.

To expose a `CO_ENV=local` server on the LAN, set `CO_WEB_HOST=0.0.0.0`
(an explicit `CO_WEB_HOST` always wins). The resolved bind host is logged at
boot so an operator can see whether the server is loopback-only or LAN-exposed.

### Why

Previously every run bound `0.0.0.0`, including local development, silently
exposing dev servers on the local network. The resolution rule (`resolve_bind_host`)
is a pure, unit-tested function; the default tightens local dev without changing
production binding.
