## CO-359 — Mobile E2E coverage in CI matrix — Pixel 7 / iPhone 14 / iPad Pro

Extended Playwright configuration to run the test suite against four named device projects:
`desktop-chromium`, `pixel-7`, `iphone-14`, and `ipad-pro`. Removed the
`test.skip(!!(vp && vp.width <= 640), …)` gates that blocked mobile runs in
`localhost-trial.spec.ts`, `pipeline-workflow.spec.ts`, `codemirror.spec.ts`,
`subtask-tree.spec.ts`, and `board-drag.spec.ts`. Added `openSidebarIfMobile()` helper
(opens the `#hamburger-btn` drawer on ≤640 px viewports) and wired it into `selectProject`
so sidebar navigation works on phone-sized devices. Sala canvas tests (`co-352-sala.spec.ts`)
keep an explicit mobile skip — that surface is desktop-only (CO-352). CI now runs a
two-project PR path (`desktop-chromium` + `pixel-7`, ≤15 min) and a full four-project
nightly matrix (adds `iphone-14` + `ipad-pro`); each matrix job uploads its HTML report
as a separate artifact for easy triage.

### Why

Mobile regressions were caught by users rather than by CI because every affected spec
file carried a blanket skip gate added when the mobile UX was unfinished. CO-358 shipped
the drawer sidebar and mobile board reflow; these gates became obsolete and have been
removed so phones and tablets are now first-class CI citizens.
