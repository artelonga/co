GIVEN UAT today seeds only empty placeholder universes (template, quilomboaraucaria, yggdrasil) on reset, with no content from prod, and the team needs to test against realistic data shape and volume,
WHEN UAT, on reset, pulls the content of yuri's prod universes via HTTP and writes it locally through the regular Vault API,
THEN UAT testing validates against real-world data without touching prod.

## Architecture

- Triggered ONLY when the UAT reset flag was just processed (not on every machine wake)
- Gated by env: `UAT_MIRROR_PROD=true`, `UAT_PROD_URL=https://co-artelonga.fly.dev`, `UAT_PROD_TOKEN=<api-token>`
- After server binds, a tokio task:
  1. Sleeps 5s for the server to be ready
  2. Logs in to local UAT as yuri (`POST /api/v1/auth/uat-login`) for write auth
  3. Fetches list of universes from prod (`GET /api/v1/universes` with bearer)
  4. For each universe: `POST /api/v1/universes` locally (409/500 = already exists, fine)
  5. PUT visibility (CO-65) to match prod's, when caller is owner
  6. Lists prod vault, GETs each file, PUTs to UAT vault
  7. Logs total entries mirrored per universe

## Failure modes

- Prod down → mirror logs error, UAT functional with empty placeholders
- Token expired → mirror fails, log says token issue, manual rotation needed
- Network slow → background task; UAT users may see content trickle in over minutes
- Same content present → vault PUT is upsert, no harm (idempotent)
- System-owned universe (e.g., quilomboaraucaria) → owner check blocks visibility flip; mirror skips visibility PUT for non-owned, content still flows

## Operational steps to enable

1. On prod (logged in as yuri), generate an API token via `POST /api/v1/auth/token` with name "uat-mirror"
2. `flyctl secrets set UAT_PROD_TOKEN=<token> -a co-artelonga-uat`
3. `flyctl secrets set UAT_PROD_URL=https://co-artelonga.fly.dev -a co-artelonga-uat`
4. `flyctl secrets set UAT_MIRROR_PROD=true -a co-artelonga-uat`
5. Trigger UAT reset (`touch /data/uat-reset.flag` + `flyctl machine restart`)
6. Verify content arrives in UAT within 2 min

## Scale notes

- Mirror at 1K entries × 100ms = 100s — acceptable for UAT reset (uncommon event)
- Larger universes (10K+ entries) → time grows linearly; add bounded concurrency (`Semaphore(5)`) when needed
- Bandwidth: full universe transfer is ~1-10 MB, negligible
- Prod side hit: ~2K read requests per mirror run; rate limiter (CO-80) would throttle if per-token limit exceeded — use admin-tier token

## Acceptance

- UAT reset + `UAT_MIRROR_PROD=true` with valid token replicates artelonga / quilomboaraucaria / rfq from prod within 2 min
- Without env vars, UAT behaves exactly as today (empty placeholders)
- Prod-side errors don't crash UAT
- yuri can still log in to UAT after mirror completes
