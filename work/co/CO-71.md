GIVEN current SQLite has fixed tables (`tasks`, `projects`, `entries`) and the manifest epic requires arbitrary content types per universe,
WHEN we migrate entry payloads to a generic `entries.payload` JSON column with declared expression indexes from the manifest,
THEN any content type can be stored and queried without DDL on user input, with index-backed performance for hot fields.

## Architecture decision

**Generic JSON payload + selective expression indexes.** NOT per-universe DDL.

- `entries.payload TEXT NOT NULL` (validated as JSON at write)
- Indexes declared in manifest (`indexes: [status, due_at]`) → server creates expression indexes:
  ```sql
  CREATE INDEX idx_entries_<universe>_status
    ON entries(universe_key, json_extract(payload, '$.status'));
  ```
- SQLite query planner uses these for indexed reads
- Manifest update with a new index → background backfill builds it without blocking writes

## Tasks

- [ ] Migration: add `entries.payload`, copy existing typed columns to JSON, keep typed columns one release as compat
- [ ] Validator: at PUT, parse payload, validate against manifest's content_type schema, reject invalid with field-path error
- [ ] Index manager: on manifest change, diff old vs new declared indexes; create/drop SQLite indexes accordingly
- [ ] Read path: typed view layer exposes payload as Rust structs based on manifest
- [ ] Type coercion: dates as ISO-8601 strings in JSON, parsed to `chrono::DateTime` at read

## Scale notes

- JSON storage uses ~10-20% more space than typed columns; acceptable
- `json_extract` queries WITHOUT an index are O(N); manifest **must** declare indexes for all hot fields
- Per-universe DBs (CO-77) make per-universe indexes scale: each universe has its own SQLite file with its own index set
- At 1M entries per universe × 5 indexes = 5M index entries per universe — fine for SQLite
- Validation cost: ~10-50µs per write with cached manifest; not a bottleneck

## Acceptance

- Manifest declaring `tarefa.status` index produces an indexed query plan (`EXPLAIN QUERY PLAN`)
- Invalid payload rejected at write with field-path error
- Manifest update that adds an index backfills without blocking writes
- Read-through delivers typed Rust structs based on manifest
