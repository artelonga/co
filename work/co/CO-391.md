## As
A CO maintainer preparing the v3.0 federation cut

## I Need
A real-axum integration test that boots `co-web` with the bridge route mounted, dials it with a real WebSocket client speaking `co.eda.bridge.v1`, completes the handshake, and asserts `bridge.connected` lands on the local bus.

## So That
- The class of failure caught locally on 2026-06-09 (axum `WebSocketUpgrade` rejecting a connect that a lenient mock accepted) cannot recur.
- The CO-side test parity matches what YG-122 puts on the Yggdrasil side, so the handshake contract is enforced from both ends.
- Future changes to handler.rs (header parsing, subprotocol negotiation, query extraction) get caught at PR time, not at first prod dial.

## Context

**Discovered 2026-06-09 during pre-flight for v3.0 federation cut.** The local co-web ⇄ yggdrasil harness produced HTTP 400 "Connection header did not include 'upgrade'" — yggdrasil fell into a 2s reconnect loop, `bridge.connected` never landed. Why nothing caught it earlier:

- CO unit tests (`handler.rs:537-558`) only cover `is_trusted_in` — three trust-list assertions. No handshake, no `WebSocketUpgrade`, no real socket.
- YG-119's integration test used a tokio-tungstenite mock server that accepted the handshake permissively.
- The contract audit passed because the env vars + trust list + token-presence check all matched spec.
- CO-374 (Playwright staging) is `todo` — doesn't exist yet.

The test below is the missing layer between unit tests and full E2E.

## Design

### Test harness

Spin up the real axum router (or just the bridge subrouter) on an ephemeral port. Use `tokio_tungstenite::connect_async` from the test to dial the running server, with the exact subprotocol + headers the Yggdrasil client sends.

```rust
#[tokio::test]
async fn bridge_handshake_accepts_trusted_source() {
    std::env::set_var("CO_BRIDGE_TRUSTED_SOURCES", "test.example.com");

    let app = build_test_app().await;   // mounts /api/v1/events/bridge
    let listener = TcpListener::bind("127.0.0.1:0").await.unwrap();
    let addr = listener.local_addr().unwrap();
    tokio::spawn(axum::serve(listener, app).into_future());

    let url = format!(
        "ws://{addr}/api/v1/events/bridge?source=test.example.com&token=anything"
    );

    let request = url.into_client_request()
        .unwrap()
        .header("Sec-WebSocket-Protocol", "co.eda.bridge.v1");

    let (mut ws, response) = connect_async(request).await
        .expect("handshake must succeed");

    assert_eq!(response.status(), 101);
    assert_eq!(
        response.headers().get("Sec-WebSocket-Protocol").map(|h| h.to_str().unwrap()),
        Some("co.eda.bridge.v1"),
    );

    // Drain the first server event — should be bridge.connected echoed via local bus.
    let first = ws.next().await.expect("server emits welcome").unwrap();
    // ... assert envelope shape
}

#[tokio::test]
async fn bridge_handshake_rejects_untrusted_source() {
    let (_addr, app) = test_server().await;
    let url = "ws://.../bridge?source=evil.com&token=anything";
    let err = connect_async(url).await.unwrap_err();
    assert!(matches!(err, ConnectError::Http(403)));
}

#[tokio::test]
async fn bridge_handshake_rejects_empty_token() {
    // source trusted, token empty → 401
}
```

### Coverage matrix

| Scenario | Expected | Why this case |
|---|---|---|
| Trusted source + non-empty token + subprotocol | 101 + `bridge.connected` | The happy path YG-119 mock falsely passed |
| Untrusted source | 403 | Regression guard for trust list |
| Empty token | 401 | Regression guard for token-presence check |
| Wrong subprotocol header | depends on spec — assert documented behavior | Locks down protocol negotiation |
| Missing `Connection: Upgrade` | 400 | The exact failure that bit us 2026-06-09 |

### What this is *not*

- Not a replacement for CO-374 (Playwright cross-deployment staging) — that's the prod-shape backstop.
- Not a load test.
- Not a federation-content test (events flowing through). One round-trip envelope is enough; CO-389/CO-383 own content semantics.
