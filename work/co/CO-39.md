GIVEN CO already has CodeMirror 6 (CO-29), Yjs CRDT (CO-31), and the Obsidian sync plugin (CO-34), but the markdown rendering across these is inconsistent (cards show truncated escape sequences, modal uses raw textarea, no rendered preview),
WHEN I unify the markdown rendering pipeline so the same parser/renderer is used everywhere — kanban cards, content cards, viewer modal, editor preview, Obsidian sync, Capacitor/Electron shells (when built),
THEN this is a **minor path** (incremental improvement, no architectural changes):

## Single Renderer

- [ ] Pick one renderer for the entire web app: **marked** (already a dep) with extensions for GFM, code highlighting, task lists, footnotes
- [ ] DOMPurify on all rendered output (XSS safety) — already a soft dep, formalize it
- [ ] New module `co-web/static/shared/markdown.js`:
  - `renderMarkdown(text, opts)` → sanitized HTML string
  - `extractFirstParagraph(text)` → for card previews
  - `wordCount(text)`, `readingTime(text)`, `headingCount(text)` → for view-dados stats
  - `extractFrontmatter(text)` → returns `{ frontmatter, body }`
- [ ] Replace ad-hoc rendering in `experiment.js`, `app.js`, conteudo cards, task modal preview

## Card Rendering

- [ ] Kanban task cards: render first paragraph (not raw markdown escapes)
- [ ] Content cards: render full markdown body with fade-out gradient (4-6 lines visible)
- [ ] Code blocks: monospace, scrollable horizontally, no syntax highlighting in cards (defer to viewer)

## Viewer Modal

- [ ] Full markdown rendering (headings, lists, tables, code, images, links)
- [ ] Code blocks: syntax highlighting via `prismjs` or `highlight.js` (CDN, lazy-loaded)
- [ ] Tables: responsive, horizontal scroll on mobile
- [ ] Images: lazy-loaded, click to zoom
- [ ] Internal links (`[[wikilinks]]`): resolve to other entries in the same universe

## Editor (CodeMirror)

- [ ] Already uses `@codemirror/lang-markdown` (CO-29)
- [ ] Add live preview pane toggle (split view: editor | rendered)
- [ ] CRDT: existing Yjs binding stays unchanged
- [ ] Auto-save draft to localStorage every 5s

## Cross-Platform Considerations

- [ ] Capacitor (CO-36, planned): renderer must work without Node — pure browser JS ✓
- [ ] Electron (CO-35, planned): same — pure browser ✓
- [ ] Obsidian plugin (CO-34, done): uses Obsidian's native renderer, just preserve markdown source ✓
- [ ] Document the contract in `co-web/docs/markdown-pipeline.md`

## Acceptance

- [ ] `cargo test` passes
- [ ] Card preview shows formatted text (no `**` or `\\n` escapes)
- [ ] Viewer modal renders all GFM features correctly
- [ ] Same markdown source produces identical output in cards, modal, and Obsidian
- [ ] Bundle size increase < 30KB (marked is small; prismjs lazy-loaded)
