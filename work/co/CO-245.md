## As

A user editing code, YAML, JSON, CSV, or similar plaintext files stored in a universe

## I Need

Inline editing of these file types in the CO web view, with syntax highlighting and save-back to vault

## So That

I don't have to download → edit locally → upload — I can iterate on a config file or script directly in the universe.

## Context

- **Principles:** §4 (reduced coupling — editor lives next to content), §6 (universal substrate for any plaintext file)
- **Scope:** After CO-242 surfaces all file types in entries, add edit affordance for plaintext types:

Supported languages (Phase 1, via CodeMirror's existing modes — already bundled at `static/shared/editor.bundle.js`):
- `code.rs` Rust
- `code.ts/.js` TypeScript / JavaScript
- `code.py` Python
- `code.r` R
- `code.sh` Bash
- `code.sql` SQL
- `code.go` Go
- `code.yaml/.yml` YAML
- `code.json` JSON
- `code.toml` TOML
- `text.csv/.tsv` CSV (with table view toggle)

Phase 2: inline run/preview for some types — e.g. CSV opens a sortable/filterable table view; YAML lints against a schema if the universe declares one.

Phase 3: a 'CO Pad' mode — non-md entries shown side-by-side with their preview (markdown ↔ rendered, CSV ↔ table, etc.).

## Acceptance

- Clicking a code/yaml/json/csv entry opens a CodeMirror editor with appropriate syntax highlighting.
- Save button writes back via vault PUT, increments `body_lines/words/chars` (CO-241).
- ctrl/cmd+S keybind works.
- Read-only fallback for unknown plaintext types.
- E2E test: upload a `.py` file, edit it inline, save, reload, content matches.

## Blast radius

Medium — frontend only; CodeMirror is already bundled. New 'inline editor' view + dispatcher in the entry router.
