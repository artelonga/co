## Contexto
A partir de **15 jun 2026**, runs headless `claude -p` deixam de usar a quota da
assinatura e passam a consumir o **pool de créditos do Agent SDK** (API rates). O
`usage.rs` somava `usage` por-mensagem, que o Claude Code **repete** entre content
blocks → **overcount 3-8x**. Com cobrança medida, a contagem precisa estar correta.

## Acceptance
- [ ] Quando o evento `result` traz `usage` cumulativo, ele **sobrescreve** a soma por-mensagem.
- [ ] Sem `usage` no `result` (claude antigo), **fallback** pra soma (comportamento original preservado).
- [ ] Teste: blocos por-mensagem inflados + `result.usage` autoritativo → reporta o result, não a soma.
- [ ] `cargo test -p co-auto` verde; `clippy`/`fmt` limpos.

## So that
A telemetria de custo do co-auto fica **correta no dia 1** da cobrança medida — ponte
até o caminho nativo OTel (CO-457).
