GIVEN comunicacao's cross-language meaning-topology currently lives INSIDE
yggdrasil-core and depends on a `COMUNICACAO_DIR=../comunicacao` sibling checkout,
so the topology logic is coupled to the game and cannot ship to prod without the
source dirs (this blocks the topologia PR #140 deploy on data-sourcing),
WHEN we make the topology "just a tool" over a portable artifact — a CO-503 tool
backed by the CO-517 Vectorizer (neural nomic via Ollama OR statistical PPMI, swap
is a flag) — consumed identically by yggdrasil/topologia, co agents, and the bot
through the canonical contract,
THEN any surface gets the meaning-topology with no sibling-dir coupling, the
artifact ships to prod, and sovereign/sacred corpora stay custodian-gated.

## Acceptance

- [ ] **Build script.** `build-topologia-data.sh` compiles the comunicacao lexicon
  + `mbya_lexicon.db` → `data/topologia.json`, one record per term with
  `gloss` / `def` / `examples` / `verses` / `co-occ` (co-occurrence counts).
- [ ] **Portable artifact, not sibling dirs.** The tool reads `data/topologia.json`
  only; nothing reads `../comunicacao` or `COMUNICACAO_DIR` at runtime. The artifact
  is self-contained and shippable.
- [ ] **`topology` tool (manifest + service).** A CO-503 manifest (`name: topology`,
  `tool_type: deterministic`, `category: language`, `dependencies: [comunicacao-lexicon]`,
  `input_schema: {word, lang?, k?}`) plus the service that, given a word, returns
  `neighbors` + `translations` over the artifact. Matches `co/src/canon_tool.rs`
  `ToolManifest`. Reviewable sample exists at `examples/integrations/topology/`.
- [ ] **CO-517 Vectorizer with swappable backend.** Neural (nomic embeddings via
  Ollama) OR statistical (co-occurrence / PPMI). The swap is a single flag; the
  statistical path runs fully offline. Same tool contract either way.
- [ ] **Consumed via the canonical contract.** yggdrasil/topologia, co agents, and
  the bot all call the tool through `CanonicalToolRegistry` — no `COMUNICACAO_DIR`,
  no in-yggdrasil topology logic. The AS-IS coupling is removed.
- [ ] **Sovereignty / CARE gate for sacred corpora.** For sacred sources
  (Ayvu Rapytã / Ifá) the artifact is **custodian-gated and never auto-shipped** —
  the build excludes them from the prod artifact unless a custodian explicitly opts
  in. Non-sacred lexicon ships freely.
- [ ] **Unblocks the topologia prod deploy.** The shipped `data/topologia.json` is
  the data source for the topologia PR #140 deploy (ship the artifact, not the
  sibling dirs).

## Notes
- Reviewable sample already drafted under `examples/integrations/topology/`
  (manifest + offline PPMI stub with an embedded tiny lexicon) — promote that shape.
- "Embedding/topology is just a tool": output feeds the CO-517 Vectorizer trait;
  neural vs statistical is a config flag, not a code change (mirrors the `embed`
  sample). Keep discovery behind `CO_ENABLE_EXTERNAL_TOOLS=1` + a trusted tools dir.
- CARE principles (Collective benefit, Authority to control, Responsibility, Ethics):
  the custodian gate is a build-time exclusion, not a runtime filter — sacred verses
  never leave the custodian's box by default.
- Pairs with CO-529 (promote comunicacao to a subscribable co universe): CO-529 makes
  the *content* canonical/subscribable; CO-528 makes the *topology* a portable tool.
