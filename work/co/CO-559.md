GIVEN the bottom-of-sidebar section labeled "Ferramentas"
(`data-i18n="sidebar.section.tools"` in `index.html`, populated by
`modules/sidebar/tools.js`, scaffolded in CO-280 and commented "dev/admin
actions") actually lists administrative/operator actions — **Implantações**
(deploy → `/deployments`) and **Histórico** (changelog → `/changelog`) — neither
of which is a tool,
WHEN a user reads "Ferramentas" expecting tools (the real, on-demand CO-503
capabilities) and instead finds deploy + changelog links,
THEN the label misleads and pollutes the "tools" namespace; rename this section
to **Gestão/Admin** for the admin actions, and reserve **Ferramentas** for actual
CO-503 tools.

## Acceptance

- [ ] Rename the current section (deploy + changelog) from "Ferramentas" to
      **Gestão** (admin/operator actions). Update the `sidebar.section.tools`
      key/usage accordingly (new key like `sidebar.section.admin`, PT "Gestão" /
      EN "Admin") so CO-555/556 i18n stays correct.
- [ ] "Ferramentas" becomes the home for real CO-503 tools (on-demand
      capabilities), not deploy/changelog links — empty/hidden until such tools
      exist rather than mislabeling admin actions.
- [ ] `modules/sidebar/tools.js` items (`deployments`, `changelog`) move under
      the renamed Gestão section; comments/IDs updated so the section name matches
      its contents.
- [ ] No regression to the deploy (`/deployments`) and changelog (`/changelog`)
      entry points themselves (see CO-558 re: changelog surface consolidation).

## Notes
- Source: `index.html` `#sidebar-tools-section` (label `sidebar-tools-label`,
  `data-i18n="sidebar.section.tools"` = "Ferramentas") + `#tools-nav`, rendered by
  `modules/sidebar/tools.js` (CO-280 Phase 1; comment: "dev/admin actions").
- Real tools = CO-503 on-demand tool capabilities; those belong under
  "Ferramentas". Deploy + changelog are admin/operator surfaces → "Gestão".
- Related: CO-558 consolidates the duplicated changelog surfaces; coordinate the
  single changelog entry point referenced from the renamed section.
