GIVEN every inbound item belongs to one of nine input types — captura bruta, nota
de reunião, email/mensagem, documento/referência, telemetria, pessoa/lead,
objetivo/meta, tarefa/decisão, prazo/evento — optionally wrapped in an envelope
(tipo/data/quem/missão/idioma), and the loop must *synthesize* it into the three
outputs (A/Jardim · B/Telemetria · C/Tarefas) without ever blocking on approval,
WHEN the bot receives an item it classifies the type, reads any envelope, and
**deterministically routes** it — splitting a mixed item across A/B/C as needed —
writing through with explicit assumptions on ambiguity,
THEN the synthesis happens by default: the bot organizes (A), digests (B), and
files tasks (C); the only deliberate hit a human makes is publish/send, never the
classification.

## Acceptance

- [x] New bot capability pack (sibling to the lifecycle/tracking packs) in
  `tools/whatsapp-bot` that classifies an item into one of the **9 input types**
  and parses the optional **envelope** (tipo/data/quem/missão/idioma); envelope
  fields override inferred ones.
- [x] **Deterministic routing** to A (Jardim, CO-501), B (Telemetria, CO-499),
  C (Tarefas, CO-500): each type has a default target set; a **mixed item splits**
  across more than one output (e.g. a nota de reunião → A page + C tasks).
- [x] **Execute-by-default / gateless:** the pack *writes through* (creates the
  page / digest / tasks) without an approval round-trip; ambiguity is recorded as
  an **explicit assumption** ("assumi: …") on the artifact, not a blocking question.
- [x] **"a definir" fallbacks:** missing assignee → `a definir`; missing
  missão/date/owner → marked `a definir` inline rather than dropped.
- [x] Per-sender scoped token from CO-490 is used for every write; unknown sender
  stays read-only ("link your account") — no service-identity fallback.
- [x] Tests cover each of the 9 types, the envelope override, the mixed-item split,
  and the assumption/`a definir` paths. `CHANGELOG-PENDING/CO-498.md`.

## Notes
- This is the **router** of the single synthesis loop; A/B/C are the three sink
  capabilities (CO-501/499/500) and CO-502 wires the live A/B + one-hit publish.
- Principle (from the loop spec): the bot never asks "should I?" — it does the
  work and *labels* what it inferred. The human reviews the result, not the plan.
