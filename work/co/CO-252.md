## As

A visitor (logged or anonymous) on the template universe

## I Need

The **`co`** universe (the public CO development project — CO-1, CO-2, ..., CO-253 tasks, roadmaps, specs) to be visible in the sidebar AND referenced from the template landing page, with a clear "this is the free software project behind what you're using" framing

## So That

Visitors who want to see how CO is built, read the roadmap, follow open issues, or contribute can find the dev project in one click. Today the `co` universe is technically public (`visibility: public-subscribable`, `is_public: true`) but it's buried in the discoverable list and indistinguishable from any other user-created public universe.

## Context

- **Today**: `co` is the parent universe (`parent_key` of `template` per `CO-141` sub-universe relations).
- **Why**: the CO team's bet is *transparency-by-default* — every visitor should see the platform's own dev board as proof that the same tools used for their kanban also run the project itself. This is also a major contribution acquisition channel.
- **Scope**:
  - Sidebar: for anonymous users, the existing fallback render path (state.userUniverses populated from `/api/v1/universes/public`) already lists `co` along with `artelonga`, `comunicacao`, etc. — but unstyled. Promote `co` to a **first-class slot** at the top: "Projeto CO (código aberto)".
  - Landing: CO-251's `index.md` rewrite includes a banner/link to `/co`.
  - Visual: optional accent or "open-source" chip on the `co` row (`role-chip` style, reusing CO-238's css class).

## Acceptance

- Anonymous visit to `/` shows `co` universe in the sidebar with a distinct visual treatment (e.g. accent color, "open source" chip, fixed top position).
- Clicking the `co` row navigates to `/co` and renders that universe's project board (the tutorial-style tasks CO-1..CO-99 plus the development tasks CO-100+).
- `co` universe's home page renders something more useful than the bare Kanban (CO-251 may do this for template; CO-252 may need a similar `index.md` for the `co` universe).

## Blast radius

- ~50 LOC: sidebar renderer special-cases `key === 'co'` (similar to how `is_template` is special-cased today).
- ~30 LOC: optional CSS for the open-source chip.
- No schema changes.

## References

- Depends on **CO-251** (template wiki rewrite) to weave the `co` link organically.
- Independent of **CO-253** (subscribe-or-login flow).
