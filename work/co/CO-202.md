## As

a user who's logged into CO

## I Need

a 🔔 bell icon in the sidebar/header that shows my notifications
dropdown (chat, DMs, invitations, mentions) with an unread badge,
plus a settings page where I can toggle channels per event type and
set quiet hours

## So That

I can browse / dismiss / act on notifications without leaving CO,
and I can configure how I get notified across email, push, and
in-app surfaces.

---

## Precondition

CO-199 (notifications schema + endpoints) must be live. CO-200 and
CO-201 are nice-to-haves but not strict preconditions — the in-app
center reads from `/me/notifications` regardless of which delivery
channels are enabled.

## Surfaces

### A. 🔔 Sidebar/header bell + dropdown

```
🔔 (3)            ← red dot badge with unread count
└─dropdown────────────────────────────────────────
  │ Notificações                  [Marcar todas]│
  ├──────────────────────────────────────────────┤
  │ 📩 Maria te enviou uma mensagem  • há 2 min  │
  │ 💬 Yuri em "Quilombo" — "Olá..."  • há 5 min │
  │ 🎁 Pedro te convidou para "Tech"  • há 1 h   │
  │ @ Yuri te mencionou em "Geral"    • há 3 h   │
  ├──────────────────────────────────────────────┤
  │              [Ver todas]                     │
  └──────────────────────────────────────────────
```

Behavior:
- Bell shows unread count from `unread_count` field of `/me/notifications`.
- Click bell → dropdown opens with the 10 most recent unread + 5 most
  recent read.
- Each row: icon by event type, summary (i18n rendered), relative
  time, click → navigate to the relevant URL + mark single notif read.
- "Marcar todas" → calls `/read-all` endpoint.
- "Ver todas" → opens the full notifications page (B below).
- Refresh on: page load, after a chat message arrives via WS (CO-194),
  after closing the dropdown.

Real-time updates: when a `message.created` WS event arrives for a room
the user is a member of (and isn't currently viewing), the bell badge
increments by 1. No polling needed for chat events. For invitations,
poll every 30s as a fallback (rare event).

### B. Full notifications page — `/notifications`

For users who want to scroll the full history. Same module mounted
in a full-page layout instead of dropdown. Reuses the existing chat
drawer width / position pattern.

- Filters: by event type (chat, DM, invitation, mention) + all/unread.
- Pagination via `?since=` cursor.
- "Marcar todas" + delete-individual (soft delete? or just dismiss
  from view? probably just mark-read).

## File-level changes

### `co-web/static/variants/a/modules/notifications.js` (new)

```js
import { state } from './state.js';
import { apiFetch } from './api.js';

let _unreadCount = 0;
let _pollTimer = null;

export async function setupNotifications() {
    await refreshUnreadCount();
    renderBellBadge();
    // Poll every 30s for invitations / fallback
    _pollTimer = setInterval(refreshUnreadCount, 30000);
}

export function teardownNotifications() {
    if (_pollTimer) clearInterval(_pollTimer);
}

async function refreshUnreadCount() {
    const resp = await apiFetch('/api/v1/me/notifications?limit=1', {}, true);
    if (resp) _unreadCount = resp.unread_count || 0;
    renderBellBadge();
}

export function bumpUnreadCount() {
    // Called by app.js when a WS chat.message event arrives for an
    // unread-eligible room.
    _unreadCount++;
    renderBellBadge();
}

function renderBellBadge() {
    const badge = document.getElementById('notif-badge');
    if (!badge) return;
    if (_unreadCount > 0) {
        badge.textContent = _unreadCount > 99 ? '99+' : _unreadCount;
        badge.classList.remove('hidden');
    } else {
        badge.classList.add('hidden');
    }
}

export async function openNotificationsDropdown() {
    const resp = await apiFetch('/api/v1/me/notifications?limit=15', {}, true);
    if (!resp) return;
    renderDropdown(resp.notifications);
    // Auto-mark-read on dropdown open? No — only on click.
}

async function onNotifClick(notifId, url) {
    await apiFetch(`/api/v1/me/notifications/${notifId}/read`, { method: 'POST' }, true);
    _unreadCount = Math.max(0, _unreadCount - 1);
    renderBellBadge();
    if (url) window.location.href = url;
}

async function markAllRead() {
    await apiFetch('/api/v1/me/notifications/read-all', { method: 'POST' }, true);
    _unreadCount = 0;
    renderBellBadge();
    openNotificationsDropdown(); // refresh dropdown content
}
```

### `co-web/static/variants/a/app.js`

```js
import { setupNotifications, bumpUnreadCount } from './modules/notifications.js';

document.addEventListener('DOMContentLoaded', () => {
    // ...existing init...
    if (state.isLoggedIn) setupNotifications();
});

// Hook into the existing WS message arrival path (chat.js) so the
// bell badge bumps when chat messages arrive in rooms not currently
// being viewed.
window.coOnChatMessageArrived = (msg, roomId) => {
    if (state.currentChatRoomId !== roomId) bumpUnreadCount();
};
```

## Acceptance

- [ ] 🔔 bell visible in header/sidebar when logged in (not for anonymous).
- [ ] Bell shows red-dot badge with unread count when > 0; hidden when 0.
- [ ] Click bell → dropdown opens with recent notifications.
- [ ] Click a notif row → marks read, navigates to URL, badge decrements.
- [ ] "Marcar todas" clears all unread; badge goes to 0.
- [ ] Receiving a chat WS event for an unread-eligible room bumps the
      badge in real time without a refresh.
- [ ] Settings section renders all 4×3 toggle matrix + frequency radio +
      quiet hours + push subscribe button.
- [ ] Toggles save optimistically via `PUT /me/notification-preferences`.
- [ ] Push subscribe button calls into CO-201's `subscribeToPush()`.
- [ ] Registered devices list shows + lets user revoke individual
      subscriptions.
- [ ] `/notifications` full-page route serves the SPA with the full
      notification list view.
- [ ] All i18n strings PT + EN.
- [ ] Anonymous users see no bell.

## Out of scope

- **Custom per-universe notification rules** ("notify me on every
  message in universe X but not Y"). Future ticket.
- **Notification grouping** ("3 new from Maria"). Display individual
  for v1; deduplicate by `tag` only at the push layer (CO-201).
- **Sound effects** on new notification arrival. Defer.
- **Notification snoozing** ("remind me later"). Defer.
- **Server-Sent Events fallback** for browsers without Push API.
  Polling at 30s covers this case.
