GIVEN data autonomy must be reachable inside WhatsApp, by a non-technical user, with
no friction on the exit,
WHEN the user sends one of three sacred commands,
THEN the bot honors it deterministically (fixed confirmations from CO-491, never
LLM-phrased) with no dark pattern:
- `mostra minhas coisas` → export their data as a file, now;
- `apaga tudo` → erase everything, after one plain confirm;
- `esquece de mim` → revoke the bot's per-user token (their kill switch).

## Acceptance

- [ ] Three intents recognized robustly (incl. pt-BR variants + voice, CO-494),
  routed **before** the model loop, answered with the deterministic `commands.*`
  strings.
- [ ] `mostra minhas coisas` → file export (CO-492) delivered in WhatsApp.
- [ ] `apaga tudo` → two-step confirm (`erase_confirm` → "apagar tudo") → erasure
  (CO-492) → `erase_done`.
- [ ] `esquece de mim` → revoke the user's `whatsapp-bot` token (co-web) + drop the
  bot's identity-store entry → `forget_done`. The bot can no longer act as them.
- [ ] No nag/dark-pattern on exit; the commands always work even when the model is
  unreachable.
- [ ] Tests: each command's effect + the deterministic copy + erase-confirm gate.

## Notes
- The kill switch is the user-controlled inverse of the CO-490 link: revoke is total
  and immediate. Reuses `delete_api_tokens_by_name(user_id, "whatsapp-bot")`.
