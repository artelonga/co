## As
The operator wanting one set of credentials to work across prod + staging

## I Need
Phase 1: shared `JWT_SECRET` + same admin password hash + same OAuth client config across both apps so yuri@artelonga.com.br logs into staging with the same creds as prod, and tokens cross-validate. Phase 2 (deferred): OIDC federation eliminating the shared-secret risk.

## So That
- The Playwright suite (CO-374) can use prod tokens against staging.
- Manual testing on staging doesn't require a separate account.
- The risk model is documented + the federation path is clear for v3.x.

## Design

### Phase 1 — shared secrets (this spec)

Fly secrets explicitly synced:

```bash
# JWT signing
flyctl secrets set JWT_SECRET=$(flyctl secrets get JWT_SECRET -a co-artelonga) -a co-artelonga-staging

# Admin seed
flyctl secrets set CO_SEED_ADMIN_EMAIL=yuri@artelonga.com.br -a co-artelonga-staging
flyctl secrets set CO_SEED_ADMIN_PASSWORD_HASH=$(flyctl secrets get CO_SEED_ADMIN_PASSWORD_HASH -a co-artelonga) -a co-artelonga-staging

# Google OAuth (same client; staging URL added as additional callback)
flyctl secrets set GOOGLE_CLIENT_ID=$(flyctl secrets get GOOGLE_CLIENT_ID -a co-artelonga) -a co-artelonga-staging
flyctl secrets set GOOGLE_CLIENT_SECRET=$(flyctl secrets get GOOGLE_CLIENT_SECRET -a co-artelonga) -a co-artelonga-staging

# Update Google OAuth client → add https://staging.co.artelonga.com.br/api/v1/auth/google/callback
```

### Risk + mitigations

| Risk | Mitigation |
|---|---|
| Staging compromise → forge prod tokens | Quarterly `JWT_SECRET` rotation across both apps |
| Shared admin password leak | Strong password + alert on unusual login pattern |
| OAuth callback URL spoofing | Pinned redirect URI; Google enforces |
| Staging logs leak prod data | Staging tests use fixture data only; no prod data on staging |

### Phase 2 — OIDC federation (deferred to CO-377-B)

Staging's OAuth server is configured with prod as a trusted issuer:
- Prod issues a JWT via `/api/v1/auth/exchange-session`
- Staging validates against prod's JWKS (`https://co.artelonga.com.br/.well-known/jwks.json`)
- No shared `JWT_SECRET`; staging can't forge prod tokens
- Already-existing OIDC routes (CO-211 catalog) provide the primitive

Implementation: ~2 weeks of work; defer until after v3.0 public launch.
