## As
A platform member, owner, or operator wanting to see what's happening RIGHT NOW

## I Need
A live timeline at `/agora` (pt-BR) and `/live` (en) — same SPA, language-routed — that connects to the event bus (CO-380) via WebSocket and renders a rolling stream of recent events scoped to my access.

## So That
- The BaaS "consented async sync" loop becomes observable: you can SEE the bus working.
- Members of a universe see their universe's pulse — who's editing, who joined, who left.
- Owners of private universes see the full firehose for their own work.
- Operators (admin) get the cross-system view: deploys, migrations, abuse signals.
- The "real-time visualization of effects on deployed interface" requirement (2026-06-06) is met.

## Design

### Routes

| Route | Language | Default |
|---|---|---|
| `/agora` | pt-BR | yes (canonical for PT speakers) |
| `/live` | en | yes (canonical for EN speakers) |

Both routes render the same SPA module; language switcher in header swaps i18n strings + redirects to the other path.

### Auth + scope

- Anonymous: only `Visibility::Public` events (e.g. aggregated visit counts, system status). No user/path detail.
- Authenticated user: own user events + member events in universes they belong to + own private universe events
- Admin: full firehose

Scope query param `?scope=mine|universe:<key>|public|admin` adjusts subscription Filter (CO-380).

### WebSocket connection

```
GET /api/v1/events?scope=mine
Upgrade: websocket
Sec-WebSocket-Protocol: co.events.v1
```

Server validates auth, applies federation rules (CO-380), pushes filtered events.

### UI

Single page with:
- **Header**: scope selector, language toggle, pause/resume button
- **Timeline column**: vertical list of events, newest at top
- **Event card**: icon (per type), human-readable summary, relative timestamp, drill-in chevron
- **Drill-in**: side panel shows full payload + context links
- **Filter chips**: by event type (CRUD | analytics | system | billing | auth)
- **Stats strip**: events/min, top types, active universes

i18n strings in `co-web/static/variants/a/i18n/{pt-BR,en}/live.json`.

### Privacy

CO-378 path redaction applies to the live timeline same as `/gestao/resumo`. Private paths show as `🔒 (private)` in user-visible events.

### Performance

- Coalesce: bursts of similar events within 500ms collapse to "5 entries updated"
- Throttle: client-side rate-limit display at 10 events/sec; queue overflow shown as "+N more"
- Reconnect: exponential backoff (1s, 2s, 4s, 8s, max 30s) on WebSocket drop

### Mobile

- Works on mobile (Wave 4 CO-358 mobile IA pass) — collapses to single column, drill-in becomes full-screen sheet
- Touch-friendly event cards (44px min)
- Battery-aware: paused when tab inactive

### Staging + localhost

Same SPA. Different bus URL:
- Prod: `wss://co-artelonga.fly.dev/api/v1/events`
- Staging: `wss://staging.co.artelonga.com.br/api/v1/events`
- Localhost: `ws://localhost:8080/api/v1/events`

Auto-detected from current origin.
