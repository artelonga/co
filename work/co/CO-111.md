## As

a CO operator preparing for an alpha cohort

## I Need

Cloudflare cache + Pages in front of the Fly-hosted `co-web`, Workers Analytics Engine wired for cheap real-time telemetry, and a tested restore drill against UAT

## To

land the data-plane edge and the cheapest viable telemetry path **without rewriting `co-core`**, while proving backups are recoverable, before any streaming infrastructure is justified

## Stories

- CO-117 — Cloudflare CDN in front of `co.artelonga.com.br` (cache rules + auth-cookie passthrough)
- CO-118 — Workers Analytics Engine ingest from `co-web` for exposure + telemetry events
- CO-119 — Restore-drill script + quarterly cadence + result log

## Acceptance gates

- [ ] `curl -I` on a static asset returns `cf-cache-status: HIT` after warmup
- [ ] One real WAE row visible in the dashboard within 60s of a synthetic exposure event
- [ ] One full restore drill into `co-artelonga-uat` from yesterday's snapshot completes in <5 min
- [ ] No Rust source moved off Fly; no `co-core` rewrite

## Out of scope

- Redpanda / Iceberg / Flink — all Phase 3+
- Multi-target deployer adapters — Phase 5
- Encryption envelope — Phase 4

## Why now

Tier 0 of `ROADMAP-V1-LAUNCH.md` is closing. Phase 0 of the platform plan piggy-backs on that work — adds the edge layer without blocking on new sprints. Cheap insurance.
