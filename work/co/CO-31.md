GIVEN CodeMirror is integrated (CO-29) and universe auth exists,
WHEN I add Yjs CRDT sync over WebSocket gated behind authentication,
THEN:

### Backend (Axum)
- [ ] New module `co-web/src/ws.rs` — WebSocket handler
- [ ] `GET /ws/doc/:universe_slug/:doc_id` — upgrades to WebSocket. Requires JWT (from `?token=` query param or cookie). Returns 401 for anonymous
- [ ] `DocRoom` struct: slug+doc_id key, connected clients (Vec<SplitSink>), Y.Doc encoded state
- [ ] `DocRoomManager` in AppState: `Arc<RwLock<HashMap<String, DocRoom>>>`
- [ ] Yjs sync protocol v1: handle sync-step-1, sync-step-2, and update messages (binary)
- [ ] On first connect to a doc: load content from SQLite → initialize Y.Doc text
- [ ] On idle (5s no updates) or last client disconnect: encode Y.Doc → save markdown back to SQLite
- [ ] Heartbeat: ping every 30s, disconnect after 60s silence
- [ ] Rate limit: max 100 messages/second per client
- [ ] Room cleanup: remove empty rooms after last disconnect

### Frontend (JS)
- [ ] Add to editor build: `yjs`, `y-codemirror.next`, `lib0` (for encoding)
- [ ] When logged-in user opens editor: create `Y.Doc`, bind to CodeMirror via `yCodemirror`, connect WebSocket
- [ ] When anonymous user opens editor: CodeMirror works locally (no sync, no WebSocket)
- [ ] Awareness protocol: cursor positions + user display name shared between connected clients
- [ ] Remote cursors shown with colored labels (username)
- [ ] "N users editing" badge in editor toolbar (only visible when connected)
- [ ] Collaboration prompt for anonymous users: when they try to open a doc that has other editors, show toast: "Crie uma conta pra colaborar" with login link
- [ ] Connection status indicator: green dot (connected), yellow (reconnecting), grey (offline/anonymous)

### Sharing Gate
- [ ] Anonymous universes: saved server-side, accessible by owner via `co_universe_owner` cookie, but NO shareable URL (`:slug` route returns 404 for non-owner visitors if universe.owner_id IS NULL)
- [ ] Logged-in universes: shareable URL works (`/co/:slug` accessible to anyone)
- [ ] When anonymous user tries to share (copy link button): show modal "Crie uma conta pra colaborar — seus dados estão salvos, basta entrar"
- [ ] After login: universe becomes shareable, CRDT sync activates

- [ ] Test: two logged-in users edit same doc → changes sync → disconnect one → reconnect → state merges
- [ ] Test: anonymous user edits locally → no WebSocket connection → login → CRDT activates
- [ ] `cargo test` passes, `cargo clippy -- -D warnings` clean
