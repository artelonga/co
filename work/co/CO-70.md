GIVEN the manifest epic (CO-63) needs a single canonical declarative format that every universe ships at its root,
WHEN we lock down `_universe.yaml`'s schema, validation rules, and migration semantics,
THEN sub-tasks CO-71..CO-75 have a stable contract to implement against.

## Manifest schema (proposed)

```yaml
# _universe.yaml
schema_version: 1
name: ArteLonga
content_types:
  - name: tarefa
    schema:
      title: { type: string, required: true }
      status: { type: enum, values: [todo, doing, done] }
      due_at: { type: date, semantic: due }
      assignee: { type: ref, target: pessoa }
    presentation:
      board: { columns: [todo, doing, done] }
      list:  { sort: [due_at, title] }
    indexes: [status, due_at, assignee]
  - name: evento
    schema:
      title:     { type: string, required: true }
      event_at:  { type: date, semantic: event }
      location:  { type: ref, target: lugar }
      attendees: { type: ref_list, target: pessoa }
    presentation:
      calendar: { date_field: event_at }
    indexes: [event_at]
doc_generators:
  - format: scaladoc
    source_dir: src/main/scala
    output_type: doc.scala
    on: sync
relationships:
  - from: tarefa.assignee
    to: pessoa
    cardinality: many-to-one
views:
  - name: roadmap
    type: gantt
    source: tarefa
    date_start: created_at
    date_end:   due_at
```

## Tasks

- [ ] JSON Schema for `_universe.yaml` v1
- [ ] Validator in `core/src/manifest.rs`: parse → typed `Manifest` struct, with errors carrying field path
- [ ] Reject manifests > 100 KB or with > 100 content types
- [ ] Forward-compat: unknown top-level keys are warnings, not errors
- [ ] Migration semantics: bump in `schema_version` triggers entry-payload migration (handled in CO-71)
- [ ] Default manifest for legacy universes (board-of-tasks, current behavior)

## Scale notes

- Manifest is loaded per-request unless cached; **must** be cached in-process LRU keyed by `(universe_key, manifest_hash)` (CO-79)
- Manifest size cap = 100 KB; one cache entry per universe = bounded memory
- At 1M cached universes × 100 KB = 100 GB. Cap LRU at 10K hot universes (1 GB) — workers cold-load on miss

## Acceptance

- Round-trip: write manifest → server validates → reload → identical bytes
- Invalid manifest rejected with clear error pointing at the failing field path
- Default manifest produces current behavior (board renders tasks)
