## As
Yuri publishing a term in a Yggdrasil lexicon sala (Mbyá Guaraní × Iorubá) — wanting it visible in CO's `comunicacao` universe within seconds, not at the next 15-min sister-repo sync tick

## I Need
A bus subscriber that consumes `entry.{created,updated}` events from the Yggdrasil deployment (origin = `yggdrasil.artelonga.com.br`) for `universe_key=comunicacao`, and upserts directly into CO's `entries` table — acting as a live overlay on top of CO-337's existing sister-repo sync. Plus a passthrough subscriber for `yggdrasil.sala.*` activity events that surfaces them in `/agora` without changing content.

## So That
- The lexicon sala UX (Yuri places a Yorùbá term anchored to a Mbyá concept) feels immediate — `/agora` lights up within 300ms, the term appears in CO's `comunicacao` universe view in <1s.
- The 15-min sister-repo poll continues as the durable confirmation channel, but stops being the user-visible latency floor.
- Lexicon term content and sala activity are cleanly separated at the event-type level (`entry.*` vs `yggdrasil.sala.*`) — no naming collision, no spurious universe creation.
- This spec is much lighter than CO-383 because the universe + path conventions already exist and CO-337 already owns durability.

## Context

**Architectural identity (clarified 2026-06-06)**: Yggdrasil's "comunicação" subsystem is **lexicon salas**, not generic chat. Users place words in native languages (mbya, yoruba, …), link them to anchor concepts, and publish terms. Published terms write to `<lingua>/terms/_users/<u>/<slug>.md` in the `comunicacao` git repo. That same repo is already the source of CO's existing `comunicacao` universe (per CO-337). So:

> **Yggdrasil salas and CO's `comunicacao` universe are feeding the same lexicon. Same identity, not a collision.**

This spec doesn't create a new universe; it accelerates an existing one.

Yggdrasil-side prerequisites (separate repo):
- **YG-99..102** (v2.2.0): comunicação subsystem GA — lobby portal, write-back to `_users/`, curation, e2e
- **YG-103** (v2.3.0): federate lexicon sala events to CO bus

CO-389 is the CO-side counterpart of YG-103.

## Design

### Live-overlay model

Yggdrasil publishes per-event when a term lands in `_users/<u>/<slug>.md`. CO subscribes; on each event:

1. Read `event.payload.body_hash`
2. Compare against existing `entries.body_hash` for `(universe_key=comunicacao, path=event.path)`
3. If hash matches existing → no-op (sister-repo sync already caught it)
4. If hash differs (or row missing) → upsert directly from event payload
5. Publish `sync.comunicacao.term_landed` to CO's own bus → `/agora` shows it

CO-337's 15-min worker continues as before. On its next tick, it verifies the bytes against the live-overlay result. Hash matches → no-op. No double-write, no schema change, no universe binding change.

### Event-type split (matches YG-103)

| Yggdrasil emits | `universe_key` | CO handles |
|---|---|---|
| `entry.created` | `comunicacao` | Direct upsert (overlay) |
| `entry.updated` | `comunicacao` | Direct upsert (overlay) |
| `entry.deleted` | `comunicacao` | Soft-delete + record `deleted_at` |
| `yggdrasil.sala.published` | (none) | Atividades + `/agora` event only |
| `yggdrasil.sala.term_contributed` | (none) | Atividades + `/agora` event only |
| `yggdrasil.sala.user_joined` | (none) | `/agora` only (anon-friendly) |

`yggdrasil.sala.*` events carry sala-id + lingua + actor-id in payload; no content mutation.

### Subscriber wiring

```rust
// co-web/src/integrations/comunicacao_live.rs
fn register(bus: &EventBus) {
    bus.subscribe(Filter {
        origin_deployment: Some("yggdrasil.artelonga.com.br".into()),
        event_types: Some(vec![
            "entry.created".into(),
            "entry.updated".into(),
            "entry.deleted".into(),
        ]),
        universe_keys: Some(vec!["comunicacao".into()]),
        paths_prefix: Some("_users/".into()),  // narrows to sala-published terms
        ..default
    }, handle_comunicacao_term_event);

    bus.subscribe(Filter {
        origin_deployment: Some("yggdrasil.artelonga.com.br".into()),
        event_types: Some(vec![
            "yggdrasil.sala.published".into(),
            "yggdrasil.sala.term_contributed".into(),
            "yggdrasil.sala.user_joined".into(),
        ]),
        ..default
    }, handle_sala_activity_event);
}

fn handle_comunicacao_term_event(event: Event) -> Result<()> {
    let payload = event.payload_as::<TermPayload>()?;
    let existing = storage.find_entry("comunicacao", &payload.path);

    if let Some(e) = existing {
        if e.body_hash == payload.body_hash {
            return Ok(());  // sister-repo sync already has it; skip
        }
    }

    storage.upsert_entry(
        universe_key: "comunicacao",
        path: payload.path,
        entry_type: "term",
        frontmatter: payload.frontmatter,
        body: payload.body,
        body_hash: payload.body_hash,
        source: "yggdrasil-live",  // marker for diagnostics
    )?;

    co_bus.publish(Event {
        event_type: "sync.comunicacao.term_landed",
        universe_key: Some("comunicacao".into()),
        payload: json!({ "path": payload.path, "lingua": payload.lingua }),
        visibility: Visibility::UniverseMembers,
        ..event
    })?;
    Ok(())
}

fn handle_sala_activity_event(event: Event) -> Result<()> {
    // No content mutation; just republish to local bus for /agora + atividades
    co_bus.publish(Event {
        event_type: format!("sync.{}", event.event_type),
        ..event
    })?;
    Ok(())
}
```

### No universe binding change

`comunicacao` universe keeps its existing `source_kind = 'remote-git'` + `remote_url = github.com/artelonga/comunicacao` from CO-337. The bus event is an overlay; the durability path is unchanged.

A diagnostic-only column added to `entries` to track overlay-sourced upserts:

```sql
ALTER TABLE entries ADD COLUMN source_marker TEXT;  -- 'yggdrasil-live' | 'remote-git' | 'vault-write' | NULL
```

Migration v66 (small, additive). Helps debug "did this entry come from the live overlay or the 15-min poll?"

### Sister-repo sync coordination

CO-337's worker remains the durable channel. Its dedup logic (compare `body_hash` of git-fetched file vs local row) means overlay-written entries don't get clobbered. When the next 15-min poll runs:
- For each file in `comunicacao` repo, compute hash
- Compare to local row's hash
- If match (which it will be after the overlay upsert) → skip
- If mismatch (the term was edited at Yggdrasil between the overlay event and the poll) → update

This ensures eventual consistency even if the event bus drops a message.

### /agora live timeline

`/agora` (CO-381) renders the new events:

| Event | Icon | Color |
|---|---|---|
| `sync.comunicacao.term_landed` | 📚 | green |
| `sync.yggdrasil.sala.published` | 🎪 | blue |
| `sync.yggdrasil.sala.term_contributed` | ✍️ | yellow |
| `sync.yggdrasil.sala.user_joined` | 👋 | gray |

Visibility: term events shown to comunicacao universe members; sala activity shown to anyone with sala access (anon-friendly per existing CO-378 redaction rules).

### Read-only enforcement (lightweight)

Since CO-337 sister-repo sync already exposed comunicacao as read-only (with edit-at-source via GitHub), no new 405-rejection middleware needed. Sala-published terms get a small badge "📜 published from sala" in the SPA reader view, distinguishing them from repo-direct content.

### Telemetry (via CO-380)

- `sync.comunicacao.term_landed{path, lingua}` per overlay-driven upsert
- `sync.comunicacao.term_landed_via_repo{path, lingua}` per CO-337 poll catch
- `sync.yggdrasil.sala.*` per sala activity event passthrough
- `sync.comunicacao.event_dedup_skipped{path}` when overlay hash matches local row (sister-repo got there first)

Surfaces in `/agora`.

## Not in scope

- **Editable round-trip** (term edited in CO writes back to Yggdrasil) — defer to v3.1+ with CO-385 conflict tree; for now CO is read-only relative to Yggdrasil-published terms (sister-repo write-back via `_users/` is Yggdrasil's job)
- **Multi-instance Yggdrasil** (events from multiple sala deployments) — single source for now
- **Term curation event types** (`yggdrasil.sala.term_curated`, `yggdrasil.sala.term_rejected`) — depends on YG-101 finishing; defer or extend payload
- **Universe binding for `comunicacao` to advertise live source** — keep current `remote-git` kind; live overlay is invisible to the binding layer
- **CO-side sala render** (showing the spatial canvas in CO's SPA) — that's the workspace primitive territory (CO-352); separate spec
