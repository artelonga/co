## As

a CO user editing the same entry from two devices (or with an Obsidian sync overlapping the web)

## I Need

an Apple-Finder-style modal that surfaces the 4 conflict actions (`Ignore`, `Replace`, `Keep both`, `Apply to all`) when a sync detects divergence, with rich diff previews

## To

ship the conflict-resolution UX the user explicitly named as a v1 requirement and that the SR plan omitted (§C.3 of the platform roadmap review)

## Given / When / Then

GIVEN CO-61 (sync protocol v1) and CO-54 (idempotency) detect divergent edits on the same entry,
WHEN the SPA receives a `409 Conflict` with both versions in the payload,
THEN it shows a modal with side-by-side diff, the 4 buttons, and an "Apply to all" checkbox that batches the same choice across the queued conflicts in the current sync round.

## Modal behaviors

| Action | Server effect | Client effect |
|--------|---------------|---------------|
| **Ignore** | Server keeps remote version; local discarded | UI reverts to remote; local change saved to "rejected drafts" trash |
| **Replace** | Server takes local version; remote discarded | UI shows local version; remote saved to "previous versions" with a restore link |
| **Keep both** | Server creates new entry `<title>.local.md`; both persist | UI shows both entries linked together |
| **Apply to all** (checkbox) | Choice persists for the rest of this sync round; modal disappears for subsequent conflicts | — |

## Visual reference

Match macOS Finder's "Replace" / "Keep both" dialog *visually* (icon, button order, monospace diff body). Use existing CO design tokens; no new framework.

## Acceptance

- [ ] Modal component in SvelteKit consuming `ConflictPayload { local, remote, base? }`
- [ ] Side-by-side diff renderer (use `diff` crate via WASM, or JS `diff` lib — implementer's call)
- [ ] All 4 actions implemented end-to-end (API + UI)
- [ ] "Apply to all" persists in component state for the conflict round (not across reloads)
- [ ] Playwright e2e: open same entry on 2 sessions, edit both, save B then A → modal appears with both versions
- [ ] Keyboard shortcuts: `1` = Ignore, `2` = Replace, `3` = Keep both, `Esc` = cancel sync round
- [ ] Translations in PT-BR (primary) and EN

## Out of scope

- 3-way merge UI (sometimes called "Merge" as a 5th option) — separate ticket if/when sync protocol supports common-ancestor reconstruction
- Conflict-free collaboration via CRDTs — that's CO-61's lower layer; this UI handles the cases CRDT cannot
- Mobile-specific layout — Capacitor work (CO-105) inherits this with touch adaptations

## Risks

- **"Apply to all" with semantically different conflicts.** Mitigation: scope only to the current round + same conflict type; document
- **Diff perf on large markdown files.** Mitigation: cap at 100 KB per side; for larger, show summary + link to view full
