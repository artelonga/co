a brain owner navigating nested universes (parent_key chains like
miguel→mse), I need to place a UNIVERSE on the canvas as a node and open it
to descend into that universe's own sala — same surface, narrower scope —
and ascend back. Fractal: salas all the way down.

## I Need

A node kind `universe` in layout_json (`{kind:"universe", key:"mse", x, y}`),
rendered distinctly; double-tap/enter descends (navigate to `/u/{key}/sala`
with a breadcrumb back-link); the parent sala remembers camera state on return.
