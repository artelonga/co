## As

A CO user at the terminal, I need `co updates` to show what changed in recent
releases, so that release notes reach me where I already am — without opening
the repo or the hosted changelog viewer.

## GIVEN / WHEN / THEN

- GIVEN an installed `co` binary, WHEN I run `co updates`, THEN the most
  recent release section of the CHANGELOG (version — date — theme + task
  entries) prints, and older releases do not.
- GIVEN `-n 3`, WHEN I run it, THEN the three most recent releases print in
  order, newest first.
- GIVEN `--all`, WHEN I run it, THEN every release header prints as a compact
  history list.
- The CHANGELOG is embedded at compile time (`include_str!`) — the notes
  always match the installed binary; no network, works offline.

## Notes

Release-day companion of CO-403 (WELCOME.md): the docs tell the story to
newcomers, `co updates` tells the latest chapter to residents. Each
`release-commit.sh` run automatically becomes the next note — zero additional
authoring.
