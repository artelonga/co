## As

A user visiting `/co/license`

## I Need

The CO universe to have a `LICENSE.md` entry rendering the project's AGPL v3 license text.

## So That

The recursive file-compat layer (CO-264) actually has all three well-known files working: CHANGELOG (200 ✅), README (200 ✅), LICENSE (404 ⚠ now).

## Context

CO-264 added the alias resolution: `/<universe>/license` → look up entry at `LICENSE.md`. The alias works (verified via candidate list). But the seed walker (CO-261 + CO-264 extensions) didn't include the actual `LICENSE` file from the repo root.

Repo has `LICENSE` (no extension — AGPL v3 text). Walker needs to:

1. Detect `LICENSE`, `LICENSE.md`, or `LICENSE.txt` at repo root
2. Upsert into co universe as entry `path = 'LICENSE.md'` with `entry_type = 'page'`
3. If the source file has no `.md` extension, wrap the body or just store as-is (markdown renderers handle plain text gracefully)

## Scope

In `co-web/src/storage/seed.rs` (the root-files walker added in CO-264):

```rust
// Extend the list of well-known root files:
let root_files = &[
    ("CHANGELOG.md", "page"),
    ("README.md", "page"),
    ("LICENSE", "page"),         // ← add
    ("LICENSE.md", "page"),      // ← add
    ("LICENSE.txt", "page"),     // ← add
];
// Use the FIRST match (so LICENSE wins over LICENSE.md if both exist)
// Normalize to entry path `LICENSE.md` regardless of source name
```

Plus the Docker build context already copies workspace root files — verify `LICENSE` is in `/usr/src/co/` at build time.

## Acceptance

- `GET https://co.artelonga.com.br/co/license` returns 200
- `GET /api/v1/universes/co/entries/LICENSE.md` returns 200 with the AGPL v3 text in body
- Same pattern applies to other universes that have a LICENSE file (once CO-267 cross-repo sync is wired)
- Test: seed walker test asserts LICENSE entry exists after `seed_root_files`

## Blast radius

- ~15 LOC in `storage/seed.rs` (extend root-files array)
- Possibly 1 line in Dockerfile to ensure `LICENSE` is copied (likely already there)
- 1 integration test
