### Pipeline (8 steps)
1. **Resolve repo** — `~/.co/repos/owner/repo/`, clone (HTTPS→SSH fallback) or `git pull`
2. **Load project** — `project.yaml` at repo root, `{KEY}-*.md` task files
3. **Select task** — same priority/blocking logic as v1
4. **Worktree** — `~/.co/worktrees/co-auto-{KEY}-{id}-{nano}/` on branch `co-auto/{KEY}-{id}-{nano}`
5. **Build context** — 5-layer context written to `.claude/co-auto-context.md`
6. **Launch Claude Code** — headless or interactive in the worktree
7. **Review + commit** — `cargo check`, detect changes; mark done/review
8. **Merge + cleanup** — push branch, `--no-ff` merge, push main; rebase on conflict (once); remove worktree on success
