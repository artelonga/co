## CO-52 — Universe Search + Subscription

### Backend
- **`GET /api/v1/universes/search?q=&limit=20`** — now returns `UniverseSearchResult` with `subscriber_count` and `owner_display_name` (joined from users table). Authenticated callers automatically exclude already-subscribed universes.
- **`POST /api/v1/universes/:slug/subscribe`** — returns **201 Created** for new subscriptions, **200 OK** for idempotent re-subscribe (was 204 before)
- **`Storage::subscribe_universe()`** — return type changed to `anyhow::Result<bool>` (`true` = newly subscribed)
- **`Storage::set_universe_visibility()`** — new public helper method
- **`UniverseSearchResult`** — new model in `models.rs`
- **5 new tests** in `storage_tests.rs`: subscribe new/idempotent, reject private universe, unsubscribe, search with subscriber_count/owner_display_name, search exclusion, list_universes_includes_subscribed

### Frontend (variant a)
- **Discover button** (search icon) in sidebar section header — hidden until logged in
- **Inline search panel**: debounced input → results with subscriber count + "Inscrever-se" button
- **Subscribe flow**: clicking subscribe calls the API, flips button to "Inscrito ✓", and adds universe to sidebar immediately
- **Visual distinction** in sidebar: owned universes have class `universe-owned`, subscribed have `universe-subscribed` (CSS can style with `font-weight: bold` for owned)
- **Right-click context menu** on subscribed universes → "Cancelar inscrição" / "Unsubscribe"
- **i18n**: 7 new keys in both Portuguese and English
