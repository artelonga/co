## CO-42 — Content Page Redesign

### Folder Hierarchy
- `buildFolderTree(entries)` builds `{ name, path, items, children }` from flat paths
- `renderFolderNode()` renders recursively with chevron, Material folder icon, name, count badge
- Folder collapse state persisted per-path in `co_folder_*` localStorage keys
- 0 folders → flat list; 1+ folders → collapsible sections with optional nesting

### Rendered Cards
- Title, markdown body (fade-gradient at 6-8 lines), tags with `#` prefix, relative date
- Hover: accent border + shadow; single-click → zoom view; double-click → zoom edit

### Zoom Viewer Modal
- Full-screen overlay with backdrop blur, `scale(0.92→1)` zoom-in animation
- Sticky toolbar: ✕ close, page title, edit pencil, info, print
- ESC key and click-outside close
- Double-click body enters edit mode; CodeMirror inline in modal
- Save persists via `PUT /api/v1/universes/:slug/entries/:path`

- Metadata: filename, path, type, slug, parent, tags, author, created/modified dates
