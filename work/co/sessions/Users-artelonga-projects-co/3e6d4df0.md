### CO-46 — Full User Telemetry (v1.0.0 → 1.1.0)

**Database (migration v16)**
- `telemetry_events` table with 14 columns: timestamp, visitor/user/session tokens, event type/name, universe key, path, JSON properties, duration, daily-salted IP hash, device/browser/OS
- 3 indexes: by timestamp, event type+name, user_id

**Backend — `co-web/src/telemetry.rs`**
- `telemetry_middleware`: server-side pageview tracking, bot filtering, UA parsing, daily-salted IP hashing (never stores raw IP), async tokio::spawn inserts (< 5ms impact)
- `cleanup_old_events()`: 90-day retention policy
- `telemetry_summary()`: aggregates unique visitors, top pages, error count, p95 latency, events by type/day

**Endpoints**
- `POST /api/v1/telemetry/event` — client event ingestion (returns 202)
- `GET /api/v1/admin/telemetry/summary` — aggregated stats (GitHub admin auth)
- `GET /api/v1/admin/telemetry/export` — CSV download (GitHub admin auth)
- `GET /co/co-dev/telemetria` — admin dashboard with cards, traffic chart, export button

**Frontend — `telemetry.js`**
- Respects `navigator.doNotTrack === '1'`
- Gated on `co_cookie_consent` (no tracking before consent)
- Auto-tracks page views, LCP, FID (PerformanceObserver), JS errors (window.onerror)
- `window.coTrack(eventName, props)` for manual interaction tracking
- Delivery via `navigator.sendBeacon` (non-blocking)

**Tests** — 9 integration tests covering: user flow simulation, retention cleanup, HTTP endpoints (202/400/401), admin dashboard HTML, auth guards
