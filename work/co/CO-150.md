## As

a user opening a board / page with images, video, or PDF embeds

## I Need

the SPA to render markdown with `<img loading="lazy" decoding="async">`, `<video preload="none">`, `<iframe loading="lazy">`, and to fetch only frontmatter + first-paragraph excerpts for off-screen entries

## To

experience real lazy load — initial paint is fast, scrolling pulls in media on demand

## Implementation

### Markdown renderer

`co-web/static/js/markdown.js` (or wherever the renderer lives) post-processes:

```js
// Rewrite ![alt](sha256:abc...) → <img>
md.renderer.rules.image = (tokens, idx) => {
    const token = tokens[idx];
    const src = token.attrGet('src');
    const alt = token.content;
    if (src.startsWith('sha256:')) {
        const sha = src.slice(7);
        return `<img src="/api/v1/universes/${universeKey}/assets/${sha}" alt="${alt}" loading="lazy" decoding="async">`;
    }
    return defaultRender(tokens, idx);
};
```

Same for `<video>` and `<iframe>` shortcodes.

### Frontmatter excerpt endpoint

```
GET /api/v1/universes/{u}/entries/{path}?excerpt=true
    → { frontmatter: {...}, excerpt: "first 200 chars of body" }
```

Used by the board view to render task cards without fetching full bodies.

### Asset browser UI

New view `/co/{u}/assets` (admin-only Phase 5; opens to all owners later):

- Grid of thumbnails (image/* mimes get inline previews; others get mime icon)
- Filter by mime prefix, tag, date range
- Search by filename
- Click → detail view with sha256, refcount, referring entries, delete button

### Image embedding flow

In the entry editor, drag-and-drop or paste an image → uploads via `POST /assets` → inserts `![alt](sha256:abc...)` into the markdown body. Round-trippable: the markdown source stays portable (sha256 is content-addressed; paths don't break).

## Acceptance

- [ ] Board view with 50 image-laden entries paints in < 1 s; images load as user scrolls
- [ ] Video plays on click without prebuffering the whole file
- [ ] Drag-image-onto-editor uploads to `/assets` and inserts `![](sha256:...)` syntax
- [ ] `?excerpt=true` returns frontmatter + 200-char excerpt
- [ ] Asset browser at `/co/{u}/assets` lists all assets with thumbnails
- [ ] Lighthouse "lazy-load images" audit passes
- [ ] CHANGELOG entry; demo screenshot in `docs/`

## Out of scope

- Mobile-specific image variants (CO-105 / future)
- Server-side thumbnail generation (client-side derives Phase 5; server-side later)
- Auto-tag extraction (EXIF, ML-based) — separate ticket
- Drag-drop video transcoding — separate ticket
