GIVEN a stranger landing on `co.artelonga.com.br` for the first time sees a kanban with cryptic tasks and no clear "what is this for / what do I do" signal, AND the timeline trio + multi-overlay is the most demoable feature in 1.21 but no one will discover it from the kanban,
WHEN we add a non-blocking three-step coach-mark banner that surfaces the views, the timeline, and the "create your own universe" call-to-action,
THEN the first 30 seconds of first-time experience point users at the platform's actual narrative ("multi-view content, dive into time, build something").

## Spec

A small floating card in the bottom-right of the viewport (≈ 320×120px). NOT a modal — does not block clicks behind it. Shows in three steps with a Next button, a step indicator (1/3, 2/3, 3/3), and a "Pular" link.

### Trigger

Show only when ALL of:
- `state.isTemplate === true` (on template universe)
- `await api.me()` returned null (anonymous visitor)
- Cookie `co_onboarded` is **not** set
- Viewport width >= 720px (skip on mobile — different UX, deferred)

### Steps (PT-BR copy)

**Step 1 — Visões**
> O Co tem várias visões do mesmo conteúdo: **Quadro**, **Tabela**, **Conteúdo**, **Linha do tempo**.
> Clique nas abas acima para alternar.

**Step 2 — Linha do tempo**
> A linha do tempo mostra eventos numa escala log: do Big Bang ao agora.
> [Abrir linha do tempo →](/shared/timeline.html?u=tempo,universo,humanity)

**Step 3 — Crie seu universo**
> Quando quiser organizar suas próprias coisas, faça login e clique em **+ Novo universo** na barra lateral.
> [Criar conta](#login)

After Step 3 (or "Pular"), set:
```
document.cookie = 'co_onboarded=1; Path=/; Max-Age=31536000; SameSite=Lax';
```

### Visual

- Background: `var(--card-bg)` with `var(--border)` border, `box-shadow: var(--shadow-md)`.
- Position: `position: fixed; bottom: 24px; right: 24px; z-index: 50;`.
- Padding: 16px. Font: 13px.
- "Próximo" button: `var(--accent)` background, white text, 6px radius.
- Step indicator: `1 / 3` etc. in small muted text top-right of the card.
- "Pular" as a small text link in the corner.

### Localisation

PT-BR by default. EN translation in a follow-up; gate copy on `window.currentLang`.

## Acceptance

- [ ] Banner appears for an anonymous visitor on the template, never for logged-in users.
- [ ] Cookie `co_onboarded=1` is set after dismissal/completion; banner does not reappear on subsequent visits.
- [ ] Clicking outside the banner does NOT dismiss it (non-blocking but persistent until interacted with).
- [ ] On viewports < 720px, banner is suppressed entirely.
- [ ] Step 2's link opens timeline in a new tab (`target="_blank" rel="noopener"`).
- [ ] Step 3's "Criar conta" opens the existing login/signup modal.
- [ ] No visible layout shift when the banner mounts.

## Telemetry (deferred)

A future ticket can wire onboarding completion rate (`onboarding.start`, `onboarding.step_2_view`, `onboarding.complete`, `onboarding.skip`) into the existing telemetry pipeline. Spec it after Wave 3 ships the admin dashboard (CO-105) so the data has somewhere to land.

## Out of scope

- Progress persistence across browser tabs (cookie-based dismissal is enough).
- Replay button for users who want to see it again.
- Logged-in-user onboarding (separate ticket — different content).
