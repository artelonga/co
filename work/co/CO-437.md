## As
Yuri avaliando modelos de execução, QUERO que o usage capturado vá além de
tokens — tool usage, tamanho de outputs, links de PR — e que o consumo quebre
**por modelo POR universo** (a tabela cruzada, não só cada dimensão isolada),
PARA medir o custo real de cada wave (ex.: Mythos em Fable) e estimar se um
modelo `mythos` futuro compensa contra Fable/Opus/Sonnet.

## Contexto técnico
- **CO-425** captura `usage` (tokens, models, cost) do `--output-format
  stream-json`. O stream também traz eventos `tool_use` (nome + contagem) e o
  texto de output — ainda não capturados.
- **CO-426** grava `usage_sessions` e expõe `GET /usage/summary?by=ONE` (uma
  dimensão por vez). Falta o **cruzamento** model × universe e os metadados.
- co-auto já abre o PR (CO-...): o link do PR existe no run mas não é reportado.

## Acceptance
- [ ] **Captura (CO-425 estendido):** o report de usage passa a incluir, do
      stream-json, `tool_uses` (mapa nome→contagem), `output_chars` (ou tokens de
      saída já temos; somar contagem de mensagens/turns), e `pr_url` (capturado do
      output do co-auto quando o PR é aberto). Tudo best-effort/default-vazio —
      nunca falha o run.
- [ ] **Schema (CO-426 estendido):** `usage_sessions` ganha colunas
      `tool_uses TEXT` (JSON), `pr_url TEXT NULL`, `turns INTEGER DEFAULT 0`.
      **Pin (pré-flight 2026-06-12):** meta-DB em `migrations.rs` está em **v75**
      (CO-426); claim **`current_version < 76`** como bloco próprio. `ALTER TABLE
      usage_sessions ADD COLUMN ...` (idempotente via guarda de versão). Sem
      `.ok()` engolindo SELECT em coluna nova; sem renumerar migrações existentes.
- [ ] **Cruzamento model×universe:** `GET /api/v1/usage/summary?by=model,universe`
      (ou `?cross=model,universe`) retorna a matriz — linhas por universo,
      colunas por modelo, células com tokens/cost/sessions. Admin-gated (mesma
      postura do CO-426). Teste de integração da matriz.
- [ ] **Dashboard:** o painel "Uso" (CO-426) ganha a visão matriz model×universe
      e mostra, por sessão, tool usage + link do PR. Tempo real pelo stream
      existente (sem polling).
- [ ] **co universe digest / report:** opcional — o digest (CO-428) pode citar o
      custo acumulado por universo se trivial; senão fica fora de escopo.
- [ ] `cargo fmt`/`clippy -p co-web -D warnings` limpos; `cargo test -p co-web`
      verde; openapi regen + api-catalog atualizado no mesmo PR.
