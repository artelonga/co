- [ ] Add after current section "4. Cookies":
  ```markdown
  ## 5. Telemetria e Análise
  
  Para melhorar a Plataforma e identificar problemas, coletamos dados de uso 
  agregados e anonimizados. **Nenhum dado pessoal é coletado sem seu consentimento.**
  
  ### Dados coletados (anônimos)
  - Páginas visitadas e tempo de permanência
  - Cliques em botões e ações principais (criar tarefa, mudar tema, etc.)
  - Erros encontrados (para debug)
  - Performance da aplicação
  - Tipo de dispositivo (desktop/mobile/tablet) e navegador
  
  ### Dados anonimizados
  - Endereço IP é convertido em hash diário (impossível reverter)
  - Identificador de visitante é aleatório, sem ligação com identidade real
  
  ### Lista completa
  Para transparência total, mantemos uma lista exaustiva de tudo que rastreamos:
  
  → [Lista completa de dados rastreados](/co/template?path=content/dados-rastreados.md)
  
  ### Como desativar
  - Habilite "Do Not Track" no seu navegador (respeitamos automaticamente)
  - Recuse cookies no banner (telemetria não é ativada)
  - Logged-in users: opt-out em Configurações → Privacidade
  ```

```markdown
# Lista completa de dados rastreados

Última atualização: abril de 2026

Esta página lista TODOS os dados que o Co coleta. Nada além disso é armazenado.

## 1. Navegação

| Campo | Descrição | Anônimo? |
|-------|-----------|----------|
| `path` | URL visitada | Sim |
| `referrer` | Página de origem | Sim |
| `universe_key` | Slug do universo | Sim |
| `view_mode` | Kanban, tabela, etc. | Sim |
| `theme` | Tema ativo | Sim |
| `language` | Idioma da interface | Sim |
| `duration_ms` | Tempo na página | Sim |

## 2. Interações

| Evento | Quando | Dados |
|--------|--------|-------|
| `task.create` | Criar tarefa | universe, project, status |
| `task.update` | Editar tarefa | universe, project, campo alterado |
| `task.delete` | Deletar tarefa | universe, project |
| `task.drag` | Mover entre colunas | de_status, para_status |
| `theme.change` | Mudar tema | de_tema, para_tema |
| `lang.switch` | Mudar idioma | de_lang, para_lang |
| `universe.create` | Criar universo | universe (slug) |
| `universe.clone` | Clonar template | source, new |
| `auth.login` | Login (sucesso/falha) | timestamp, sucesso |
| `auth.logout` | Logout | timestamp |
| `modal.open` | Abrir modal | nome do modal |
| `search.query` | Buscar | hash do termo (não o termo) |

## 3. Performance

| Métrica | Descrição |
|---------|-----------|
| `page_load_ms` | Tempo de carregamento |
| `time_to_interactive_ms` | Tempo até interativo |
| `api_call_duration_ms` | Latência de cada API |
| `ws_connect` | Conexão WebSocket |
| `cache_hit` | Cache HIT/MISS |

## 4. Erros

| Campo | Descrição |
|-------|-----------|
| `error_type` | Tipo (4xx, 5xx, JS exception) |
| `error_path` | URL onde aconteceu |
| `error_message` | Mensagem (sem dados pessoais) |
| `stack_trace` | Stack trace (anonimizado) |

## 5. Identificação anônima

| Campo | Descrição | Como é gerado |
|-------|-----------|---------------|
| `visitor_token` | Identificador único do visitante | nanoid aleatório, salvo em cookie |
| `session_id` | ID da sessão atual | Aleatório, expira em 30min |
| `ip_hash` | Hash do IP | SHA256(IP + sal_diário) |
| `ua_device` | Categoria de dispositivo | desktop/mobile/tablet |
| `ua_browser` | Navegador | chrome/firefox/safari/etc |
| `ua_os` | Sistema operacional | windows/macos/linux/ios/android |

## 6. Dados de conta (apenas para usuários logados)

| Campo | Quando |
|-------|--------|
| `user_id` | Sempre que logado |
| `email` | Apenas no login (autenticação) |
| `display_name` | No registro |
| `created_at` | Data de criação da conta |
| `last_login_at` | Última sessão |

## 7. O que NÃO rastreamos

- ❌ Endereço IP bruto (apenas hash diário)
- ❌ Senhas (apenas hash Argon2)
- ❌ Conteúdo de tarefas/notas (apenas metadados de criação)
- ❌ Cookies de terceiros
- ❌ Pixels de publicidade
- ❌ Fingerprinting de navegador
- ❌ Dados biométricos
- ❌ Localização precisa
- ❌ Histórico fora do Co
- ❌ Identificadores de outras plataformas

## Retenção

- Eventos detalhados: **90 dias**
- Agregados anônimos: **mantidos indefinidamente**
- Dados de conta: enquanto a conta estiver ativa
- Após exclusão: 30 dias para remoção completa

## Seus direitos (LGPD)

Você pode a qualquer momento:
- Solicitar uma cópia dos seus dados: yuri@artelonga.com.br
- Pedir exclusão completa
- Desativar telemetria (cookie consent)
- Exportar todo seu conteúdo (Markdown nativo)

---

*Este documento é exaustivo. Se encontrarmos algo não listado, atualizamos imediatamente.*
```
