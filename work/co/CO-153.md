## As

a topologia consumer following a `concept: co://concepts/mother.md` link from `guarani-mbya/terms/jaryi.md`

## I Need

CO's `entry_relations` table to include a `to_universe` column so cross-universe references resolve through the relation graph (currently they're stored as untyped strings on the entry's frontmatter)

## To

let `topologia-co-adapter::CoLanguagePlane` resolve a `Term::concept` field into the actual `Concept` row, and let CO query "what terms across all language planes realize concept X" via `entry_relations`

---

## Schema change

Per-universe `entry_relations` (currently universe-local):

```sql
-- before
CREATE TABLE entry_relations (
    universe_key  TEXT NOT NULL,
    from_path     TEXT NOT NULL,
    to_path       TEXT NOT NULL,
    relation_type TEXT NOT NULL,
    created_at    TEXT NOT NULL,
    PRIMARY KEY (universe_key, from_path, to_path, relation_type)
);

-- after (add to_universe)
ALTER TABLE entry_relations ADD COLUMN to_universe TEXT;
-- NULL = same universe as the from-side (back-compat)
CREATE INDEX idx_er_to_universe ON entry_relations(to_universe, to_path)
    WHERE to_universe IS NOT NULL;
```

Use the CO-137 `ensure_column` pattern so the migration is drift-safe.

## Resolver

```rust
// core/src/relation.rs
pub struct CrossRef {
    pub universe: Option<String>,  // None = same as from-side
    pub path: String,
}

pub fn parse_co_uri(s: &str) -> Option<CrossRef> {
    if let Some(rest) = s.strip_prefix("co://") {
        let (u, p) = rest.split_once('/')?;
        Some(CrossRef { universe: Some(u.into()), path: p.into() })
    } else {
        Some(CrossRef { universe: None, path: s.into() })
    }
}
```

Then in `extract_relations`: when a frontmatter ref-typed field's value parses as a `co://` URI, populate `to_universe`. Otherwise leave NULL (same universe as today).

## Query API

```
GET /api/v1/universes/concepts/relations/inbound?path=concepts/mother.md
→ [{ from_universe: "guarani-mbya", from_path: "terms/jaryi.md", relation_type: "concept" },
   { from_universe: "yoruba",       from_path: "terms/iya.md",   relation_type: "concept" },
   ...]
```

Mirror endpoint for outbound relations.
