## Goal

Move from direct cross-feature function calls to an in-process event bus, and unify the three current worker patterns behind a shared `Worker` trait + supervisor so that signals propagate via events and workers gain a uniform lifecycle.

## Children

- CO-220 — Replace cross-feature direct calls with in-process event bus
- CO-223 — Define shared `Worker` trait + lifecycle (embedding + notification + push workers)

## Acceptance

3+ existing direct calls (`invitation → notification`, `proposal → notification`, `entry-write → embedding`) routed through the event bus; all workers implement `Worker` with start/stop/health.
