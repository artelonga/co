## As

operator do artelonga.com.br

## I Need

`POST /api/v1/telemetry/events` (que já existe em `co-web/src/telemetry.rs:1116`) aceitar requests cross-origin de `https://artelonga.com.br`, AND a row inserida ter `universe_key = "artelonga"` (vindo do campo `site` do payload — hoje provavelmente fica NULL)

## So That

eventos de page_view deixem a fila localStorage do artelonga (cap 1000) e cheguem no `telemetry_events`, ficando disponíveis pra agregação por universe (CO-180 popularity, CO-179 dashboard).

---

## Estado atual

- `POST /api/v1/telemetry/events` — handler existe (`marketing_events_handler`, telemetry.rs:731). Aceita exatamente o shape que `analytics.js` produz.
- `hash_ip_daily()` — implementado (telemetry.rs:34).
- **Gap 1**: CORS pra `artelonga.com.br` provavelmente não está liberado (verificar). Sem ACAO header, browser bloqueia o POST.
- **Gap 2**: `marketing_events_handler` constrói `EventRow` mas (verificar) não copia `ev.site` pra `universe_key` — fica NULL. Sem isso, queries por universe ficam vazias.

## Implementação

### 1. CORS allow `https://artelonga.com.br`

Adicionar à layer CORS existente (provavelmente em `server.rs`). Permitir:
- Origin: `https://artelonga.com.br` (e `https://www.artelonga.com.br` se for usado)
- Methods: `POST, OPTIONS`
- Headers: `Content-Type`
- `credentials: false` (cliente usa `credentials: "omit"`)

Escopar a regra permissiva apenas a `/api/v1/telemetry/events` (e às rotas de CO-179/180 quando lançarem). Rotas admin mantêm CORS estrito.

### 2. Populate `universe_key`

Em `marketing_events_handler`, no loop que constrói `EventRow`s:

```rust
universe_key: Some(ev.site.clone()),  // hoje é None ou ev.site é ignorado
```

Sanity check: `ev.site` non-empty, ≤ 64 chars. Caso contrário deixa NULL (não falha — só não escopa).

### 3. Index pra performance

```sql
CREATE INDEX IF NOT EXISTS idx_telemetry_universe_time
  ON telemetry_events(universe_key, timestamp);
```

Migration leve. Toda query de CO-179/180 vai filtrar `WHERE universe_key = 'artelonga' AND timestamp >= now - days` — esse index torna O(events_artelonga) em vez de O(total).

### 4. Wire o cliente (não nesse ticket)

Mudança de uma linha em `assets/analytics.js:48` no repo artelonga/ArteLonga:
```js
const ENDPOINT = "https://co.artelonga.com.br/api/v1/telemetry/events";
```

Tracker isso como follow-up separado nesse repo.

## Critérios de aceitação

- [ ] Preflight `OPTIONS` de `https://artelonga.com.br` retorna 200/204 + ACAO header.
- [ ] `POST` com `site: "artelonga"` no payload insere row com `universe_key = "artelonga"`.
- [ ] Index `(universe_key, timestamp)` aplicado.
- [ ] Admin telemetry endpoints continuam com CORS estrito (sem regressão).
- [ ] `docs/analytics-api.md` documenta CORS allowlist + URL canônica do endpoint.
- [ ] Integration test cobre preflight + POST.
