## As
Miguel (e qualquer visitante), QUERO entrar no co.artelonga.com.br com minha
conta do GitHub, PARA não criar mais uma senha.

## Contexto técnico
Hoje só existe `oauth_google.rs` (login Google, full OIDC code-flow) e
`github_auth.rs` (verificação de PAT de admin — NÃO é login). Esta story
adiciona o OAuth-login do GitHub espelhando exatamente o padrão Google.

## Acceptance Criteria
- `GET /api/v1/auth/github/start?return_to=` redireciona ao consent do GitHub
  (state JWT assinado: return_to + nonce + exp, mesma postura do Google).
- `GET /api/v1/auth/github/callback?code=&state=` troca code→token, busca
  `GET /user` + email verificado, find-or-create por `users.github_login`
  (nova coluna) e cai pra email, seta cookie de sessão, redireciona ao
  return_to safelisted.
- Env: `GITHUB_OAUTH_CLIENT_ID` / `GITHUB_OAUTH_CLIENT_SECRET` (distintos do
  PAT de admin); endpoints retornam 503 quando ausentes; botão "Entrar com
  GitHub" some quando não-configurado.
- email não-verificado → 401. Reusa `maybe_attach_co_handover_token` (CO-186).
- Teste de integração do round-trip state + find-or-create.
