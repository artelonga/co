## As

a logged-in user in a universe

## I Need

a chat drawer that opens from the sidebar (or from the yggdrasil game
lobby's chat panel), shows the current room's history, lets me type
messages, and updates live as other people post

## So That

the chat backend from CO-193/CO-194 becomes a thing I can actually use,
and the yggdrasil game lobby has a real conversation surface.

---

## Precondition

CO-193 (REST) + CO-194 (WebSocket) must be live. This ticket is pure
frontend — it adds a module that consumes both.

## Surfaces

### A. CO sidebar drawer (primary surface)

Add a `💬 Chat` button at the bottom of the sidebar, below the
"Descobrir" section from CO-192. Click → slides a drawer in from the
right. Drawer state:


Layout:
- Left rail: room list, "+ Nova sala" (owner/admin only), presence list.
- Right pane: scrollback (newest at bottom, like Slack/Discord/Telegram),
  composer at the bottom.
- Drawer width: 480px on desktop; full-screen modal on mobile (<768px).

State persists in localStorage: last-open room per universe, drawer
open/closed.

### B. Yggdrasil lobby panel

When the yggdrasil game lobby route is active (path TBD — likely
`/yggdrasil` or a special universe slug), embed the chat drawer
inline as a side panel of the lobby instead of overlaying as a
drawer. Same module, different mount mode.

Mount mode passed via prop / DOM attribute:
- `data-mode="drawer"` → overlay on the right
- `data-mode="panel"` → inline, takes its own column in the parent grid

### `co-web/static/variants/a/app.js`

```js
import { mountChat, destroyChat } from './modules/chat.js';

// Open/close handlers
document.getElementById('btn-open-chat').addEventListener('click', () => {
    document.getElementById('chat-drawer').classList.remove('hidden');
    mountChat({
        universeSlug: state.currentUniverseSlug,
        mode: 'drawer',
        container: document.getElementById('chat-drawer'),
    });
});

// Cleanup on universe switch
function onUniverseSwitched() {
    destroyChat();
    document.getElementById('chat-drawer').classList.add('hidden');
}
```

## Reconnect behavior

If the WS drops (network blip, server restart):
1. Show `chat.connection_lost` banner above the scrollback.
2. Exponential backoff reconnect: 1s, 2s, 4s, 8s, max 30s.
3. On reconnect, fetch any messages posted while disconnected via
   REST `GET /messages?before=<latest_seen_id>` (CO-193 cursor pagination
   actually goes backward, so use forward-cursor: query newest, splice
   anything with id > latest_seen_id, scroll-to-bottom if user was at
   bottom before disconnect).
4. Remove the banner on successful reconnect.

## Markdown rendering

Messages are rendered with a minimal sanitizer:
- `**bold**`, `*italic*`, `` `code` ``, ```` ``` blocks ```` ``` ```` , URLs auto-linked
- HTML stripped/escaped — no raw HTML
- Use the existing markdown renderer already on the page if available;
  otherwise hand-roll a tiny subset (the message dataflow doesn't need
  a full CommonMark parser).

## Accessibility

- Drawer is keyboard-traversable (Tab cycles rail → input → send).
- `Esc` closes drawer.
- Scrollback uses `aria-live="polite"` for new messages.
- Focus moves to composer when drawer opens.

## Acceptance

- [ ] Sidebar shows `💬 Chat` button when logged in (not for anonymous).
- [ ] Click → drawer slides in, defaults to `general` room of current
      universe.
- [ ] Switching rooms closes old WS and opens new one.
- [ ] Posting via composer hits REST `POST /messages`, optimistic
      append in scrollback, replaced when `message.created` echo arrives.
- [ ] Other users' messages appear within ~500ms of their post.
- [ ] Presence rail updates on join/leave.
- [ ] Mobile (<768px): drawer fills screen, rail collapses to a
      hamburger.
- [ ] Yggdrasil lobby route renders chat in `data-mode="panel"` inline.
- [ ] Reconnect after kill-process succeeds within 8s.
- [ ] Viewer/subscriber roles see composer disabled with hint text.
- [ ] Owner/admin sees "+ Nova sala" button; member doesn't.
- [ ] All i18n strings PT + EN.
