## As
The platform operator ensuring the OpenAPI contract matches the running implementation

## I Need
A check that probes every declared endpoint on `staging.co.artelonga.com.br` and verifies the response shape matches `openapi.yaml` — catching drift between declared contract and live behavior.

## So That
- CO-350's static drift check already prevents catalog/code/openapi.yaml divergence. This adds the third axis: **actual runtime response shapes**.
- A client (Yggdrasil, ArteLonga, third-party) consuming `openapi.yaml` is guaranteed the staging surface matches.
- Wave 4 PRs that subtly change response shapes get caught before prod.

## Design

### Probe + assert pipeline

New `scripts/contract/probe-staging.ts`:

1. Parse `co-web/openapi.yaml` → list of `(path, method, expected_response_schema)`
2. For each endpoint:
   - Send a minimal valid request (use OpenAPI examples or skip if path params can't be inferred)
   - Compare status code + response shape against spec
   - Report mismatches
3. Exit 1 if any drift

### Auth strategy

- Anonymous endpoints: probed without auth
- Authed endpoints: use staging admin (yuri) token from `CO_STAGING_ADMIN_TOKEN` secret
- Token endpoints (vault): skip in probe (require fresh issuance)

### Schema validation

Use `ajv` for JSON Schema validation. Each response → JSON.parse → ajv.validate against the path's response schema.

### CI hook

`.github/workflows/contract-probe.yml`: runs after every staging deploy (CO-379), gates the prod release workflow.

## Acceptance

- [ ] Probes every endpoint in `openapi.yaml`
- [ ] Detects status code drift (declared 200, actual 500)
- [ ] Detects response shape drift (missing required field, extra field, wrong type)
- [ ] Skips token-issuance endpoints + ones with unparameterized path params
- [ ] Outputs `contract-probe-report.json` + human-readable summary
- [ ] CI fails if drift detected; PR comment posted with diff
- [ ] Blocks prod-release workflow until green

## Blast radius

- ~250 lines `scripts/contract/probe-staging.ts`
- 1 new GitHub Action
- 0 production code changes
- 1 new secret (`CO_STAGING_ADMIN_TOKEN`)

## Dependencies

- CO-350 ✓ shipped — openapi.yaml maintained

## Not in scope

- Multi-version contract validation
- Cross-deployable contract checks (yggdrasil's API also)
- Performance assertions on the probe (just shape, not latency)
