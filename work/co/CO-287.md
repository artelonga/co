## What this slice does

After CO-286 (embedding sidecar) has run in production for 1 week, downsize co-artelonga from its current 512MB to 256MB. Saves ~$3/mo. Requires 48h observation window post-flip to confirm no OOM under realistic load.

## Scope

Pre-flight (must be true before starting):

- [ ] CO-286 deployed and stable for ≥7 days
- [ ] `/admin/deployments` shows co-artelonga steady RSS ≤ 200MB during peak hour
- [ ] No OOM events in `flyctl logs -a co-artelonga --no-tail | grep -i "out of memory"` in the last 7 days

Then:

- [ ] `flyctl scale memory 256 -a co-artelonga`
- [ ] Observe for 48h via `flyctl logs` + the deployment dashboard
- [ ] If p95 latency regresses by >20% OR any OOM event fires → revert: `flyctl scale memory 512 -a co-artelonga`
- [ ] Document final size in `docs/infra/fly-baseline-2026-05.md` (append "Post-CO-287" section)

## Acceptance

- [ ] co-artelonga runs on shared-1x 256MB for 7 days post-flip with zero OOM
- [ ] p95 request latency unchanged (within 10% of pre-flip baseline)
- [ ] WebSocket connections (chat, sync) stay stable — no disconnects beyond normal noise

- Right-sizing other apps — they're already minimal post-CO-285
