## As
The platform operator (and visitor / member / owner) wanting real-time observability across CRUD, analytics, billing, sync, and presence — all flowing through one spine

## I Need
A universal event bus that every state-changing route publishes to. Subscribers (atividades log, analytics aggregator, billing handler, sala presence broadcast, KB indexer, SPA live timeline) register filters and consume events. Federated by user/universe visibility per the privacy matrix.

## So That
- The 6+ fragmented event paths (atividades sync write, analytics batch, billing sync, sala presence, sync polling, KB push) consolidate into ONE pattern.
- Real-time visualization (CO-381) becomes trivial: SPA subscribes to scoped event stream.
- The Yggdrasil notes integration (CO-383) plugs in as another producer.
- Future Redis / NATS swap is a config flip (CO-365 trait pattern).
- This is foundational for v3.0 public launch — every later observability work hooks the bus.

## Context

Today's event paths (pre-bus):
| Surface | Mechanism | Lag |
|---|---|---|
| Atividades log (CO-361) | Sync write to `atividades` table | 0 |
| Analytics rollups (CO-340) | Async batch via tokio::spawn | 1-60s |
| Billing events (CO-366 pending) | Sync writes | 0 |
| Sala presence (CO-353 was planned) | WebSocket lobby | 100-300ms |
| Sister-repo sync (CO-337) | 15-min cron poll | 0-15min |
| KB ingest (CO-367 pending) | Bearer-token push | depends on producer |
| Atividades audit feed | Read-only query | manual refresh |

Generalize all to one bus + subscriber model.

## Design

### Core types

```rust
// co-web/src/eda/event.rs
#[derive(Clone, Debug, Serialize)]
pub struct Event {
    pub id: String,                      // ULID; chronologically sortable
    pub event_type: String,              // 'entry.created' | 'lead.captured' | 'billing.paid' | ...
    pub universe_key: Option<String>,    // None for system-wide events
    pub user_id: Option<String>,         // None for anon / system
    pub payload: serde_json::Value,      // event-specific data
    pub visibility: Visibility,
    pub created_at: DateTime<Utc>,
}

#[derive(Clone, Debug, Serialize)]
pub enum Visibility {
    Public,       // anyone can see
    UniverseMembers,
    UniverseOwner,
    UserOnly,
    System,       // admin only
}
```

### The bus

```rust
// co-web/src/eda/bus.rs
#[async_trait]
pub trait EventBus: Send + Sync {
    async fn publish(&self, event: Event) -> Result<()>;
    fn subscribe(&self, filter: Filter) -> Receiver<Event>;
    fn name(&self) -> &'static str;
}

pub struct Filter {
    pub event_types: Option<Vec<String>>,
    pub universe_keys: Option<Vec<String>>,
    pub user_ids: Option<Vec<String>>,
    pub min_visibility: Visibility,
}
```

### Implementations (pluggable)

| Impl | Status | File |
|---|---|---|
| **`TokioBroadcastBus`** | full (default, single-machine) | `co-web/src/eda/tokio_bus.rs` |
| **`RedisBus`** | stub (v3.x, multi-machine) | `co-web/src/eda/redis_bus.rs` (`#[cfg(feature = "eda-redis")]`) |
| **`NatsBus`** | stub (v3.x+, federation) | `co-web/src/eda/nats_bus.rs` (`#[cfg(feature = "eda-nats")]`) |

Env var: `CO_EDA_BACKEND=tokio` (default) | `redis` | `nats`.

### Federation rules (per the privacy matrix)

| Event type | Public | Member | Owner | System (admin) |
|---|---|---|---|---|
| `analytics.visit` | aggregated counts only | aggregated | full (path data, CO-378 redacted) | full |
| `entry.{created,updated,deleted}` (public universe) | visible | full | full | full |
| `entry.{created,updated,deleted}` (private universe) | hidden | full (if member) | full | full |
| `auth.{login,logout}` | hidden | own only | own + universe-member logins | full |
| `billing.*` | hidden | hidden | own only | full |
| `sync.{remote_pull,push}` | hidden | hidden | own only | full |
| `system.{deploy,migration}` | aggregated status | aggregated | aggregated | full |
| `workspace.cursor` | hidden | full (in same sala) | full | hidden (not interesting) |
| `kb.ingest` | hidden | hidden | own only | full |

Filter enforces visibility server-side BEFORE pushing event to subscriber.

### Backward-compat shim

Existing sync writes to `atividades` table CONTINUE. The bus ADDS a fanout layer. Producers call:

```rust
storage.write_atividade(&event)?;  // existing
event_bus.publish(event.into())?;   // new
```

Wrapper macro `publish_atividade!(...)` does both atomically. Migration is incremental — refactor producers one at a time without breaking the world.

### Subscribers (initial)

- **AtividadesPersistor**: subscribes to all → writes to `atividades` table (already exists; now also fed by bus)
- **AnalyticsAggregator**: subscribes to `analytics.*` → rollups into `analytics_rollups`
- **BillingPersistor**: subscribes to `billing.*` → writes `billing_events`
- **SalaBroadcaster**: subscribes to `workspace.cursor` + `workspace.entry_placed` + `workspace.entry_linked` → WebSocket fanout (replaces CO-353 lobby)
- **KbIndexer** (CO-367): subscribes to `entry.{created,updated}` → KB index
- **LiveTimeline** (CO-381): subscribes to scoped events → WebSocket fanout to SPA

### WebSocket fanout

`/api/v1/events?scope=...` (CO-381 spec) — opens a WebSocket; server-side filter applies visibility rules; client receives stream.

### Persistence + replay

Events ALSO append to `event_log` table for replay:

```sql
CREATE TABLE event_log (
    id TEXT PRIMARY KEY,
    event_type TEXT NOT NULL,
    universe_key TEXT,
    user_id TEXT,
    payload_json TEXT,
    visibility TEXT NOT NULL,
    created_at TEXT NOT NULL
);
CREATE INDEX idx_event_log_created ON event_log(created_at DESC);
CREATE INDEX idx_event_log_universe ON event_log(universe_key, created_at DESC);
```

Retention: 30 days default (configurable). Older events compact into rollups.

### Telemetry

Per CO-361 atividades (still works — atividades is now a subscriber, not a primary):
- `event_type = system.eda.published` per publish (sampled at 1%)
- `event_type = system.eda.subscriber_disconnect` on subscriber drop
