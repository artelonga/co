GIVEN CO needs to debug issues and improve UX based on real usage, but must respect user privacy and LGPD,
WHEN I implement comprehensive telemetry that captures behavior without PII,
THEN:

## What to Track

### Page views & navigation
- [ ] Path visited
- [ ] Referrer (internal vs external)
- [ ] Universe slug
- [ ] View mode (kanban, table, content, etc.)
- [ ] Theme active
- [ ] Language
- [ ] Device type (desktop/mobile/tablet — from User-Agent)
- [ ] Screen size bucket (small/medium/large)
- [ ] Duration on page

### Interactions
- [ ] Task created/updated/deleted/dragged
- [ ] Theme changed
- [ ] Language switched
- [ ] Universe created/cloned
- [ ] Login attempts (success/failure, no password)
- [ ] Modal opens (which modal)
- [ ] Search queries (anonymized — hash if not logged in)
- [ ] Errors encountered (4xx/5xx with path)

### Performance
- [ ] Page load time
- [ ] Time to interactive
- [ ] API call durations (p50/p95/p99 per endpoint)
- [ ] WebSocket connection events
- [ ] Cache hit rate

### Anonymous identification
- [ ] Visitor token (random nanoid, in cookie, no PII)
- [ ] IP hash (SHA256 + daily salt, never raw IP)
- [ ] Session ID (random, expires after 30min idle)

## What NOT to Track
- Raw IP addresses
- Passwords (obviously)
- Email addresses (except in users table for auth)
- Content of created entries (only metadata: created/updated counts)
- Personal information

## Schema

- [ ] New table `telemetry_events`:
  ```sql
  CREATE TABLE telemetry_events (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      timestamp TEXT NOT NULL,
      visitor_token TEXT,           -- anonymous visitor ID
      user_id TEXT,                 -- if logged in
      session_id TEXT,
      event_type TEXT NOT NULL,     -- 'pageview', 'interaction', 'error', 'performance'
      event_name TEXT NOT NULL,     -- e.g. 'task.create', 'theme.change'
      universe_key TEXT,
      path TEXT,
      properties TEXT,              -- JSON: event-specific data
      duration_ms INTEGER,
      ip_hash TEXT,                 -- daily-salted SHA256
      ua_device TEXT,               -- 'desktop'/'mobile'/'tablet'
      ua_browser TEXT,              -- 'chrome'/'firefox'/'safari'
      ua_os TEXT
  );
  CREATE INDEX idx_telemetry_time ON telemetry_events(timestamp);
  CREATE INDEX idx_telemetry_event ON telemetry_events(event_type, event_name);
  CREATE INDEX idx_telemetry_user ON telemetry_events(user_id);
  ```

## Backend

- [ ] Middleware `telemetry_middleware` in `co-web/src/telemetry.rs`
- [ ] Async batched inserts (don't block request)
- [ ] Endpoint `POST /api/v1/telemetry/event` for client-side events
- [ ] Endpoint `GET /api/v1/admin/telemetry/summary` (admin only) — aggregated stats
- [ ] Retention policy: 90 days, then aggregate + delete raw rows

## Frontend

- [ ] `telemetry.js` shared module
- [ ] `track(eventName, properties)` function
- [ ] Auto-track page views on route change
- [ ] Auto-track errors via `window.onerror`
- [ ] Auto-track performance via `PerformanceObserver`
- [ ] Respect Do Not Track header (`navigator.doNotTrack`)
- [ ] Respect cookie consent (off until accepted)

## Admin Dashboard

- [ ] `/co/co-dev/telemetria` (admin view)
- [ ] Cards: total visitors, unique visitors, top pages, error rate, p95 latency
- [ ] Charts: traffic over time, popular themes, popular layouts
- [ ] Export to CSV

- [ ] Admin dashboard shows live data
