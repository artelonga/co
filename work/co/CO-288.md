## What this slice does

Extends CO-273's `/admin/deployments` dashboard with a cost column and total-bill estimate. Adds a Fly-ops runbook so future contributors don't have to rediscover the suspend/sidecar/right-size patterns.

## Scope

Backend (~80 LOC):

- [ ] Helper in `co-web/src/admin/deployment_dashboard.rs`: `estimate_monthly_cost(machine_size_factor: f32, ram_mb: u32, uptime_ratio: f32) -> f32`
- [ ] Apply: `cost = ram_factor × cpu_factor × uptime_ratio × hourly_rate × 730` (hours/month)
- [ ] Include cost field in the API response from `GET /api/v1/admin/deployments`
- [ ] Sum across all units for a total

Frontend (~60 LOC):

- [ ] New column "Est. monthly cost" in the dashboard table at `/admin/deployments`
- [ ] Footer row: "Estimated total monthly Fly spend: $X.YY" (sum of all units' cost field)
- [ ] Tooltip on the column explaining: cost = (machine_size × uptime_ratio × Fly hourly rate × 730)

Runbook (~1 page docs):

- [ ] New file `docs/infra/fly-runbook.md` covering:
  - How to suspend an app (the auto_stop_machines + min_machines_running pattern from CO-285)
  - How to scale memory (the CO-287 pattern with observation window)
  - When to consider extracting a sidecar (the CO-286 pattern; criteria: RAM-heavy worker that's idle most of the time)
  - How to revert each change
- [ ] Update `CLAUDE.md` deployment section with link to fly-runbook.md

## Acceptance

- [ ] Visit `/admin/deployments` → see "Est. monthly cost" column on every row
- [ ] Footer shows total in dollars
- [ ] Cost numbers are within 20% of the actual Fly billing portal monthly total
- [ ] `docs/infra/fly-runbook.md` exists and is linked from CLAUDE.md

## Not in this phase

- Moving to a different cloud (out of CO-281 scope entirely — that's a future epic)
- Real-time billing API integration (Fly doesn't expose hourly billing data; estimate from machine state is good enough)
