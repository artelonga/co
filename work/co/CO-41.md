GIVEN quilombo-blog has its own deployment at quilombo-araucaria.fly.dev with SQLite content (publicacoes, eventos, missoes, usuarios, comentarios) and a complete design system in `static/design-system.html`,
WHEN I create a public Co universe `quilomboaraucaria` that mirrors this content with the quilombo-blog UI tokens,
THEN:

## Universe Setup

- [ ] Seed universe `quilomboaraucaria` (public, owned by `system`)
- [ ] Apply custom theme based on quilombo-blog tokens:
  - Primary: `#2d4a22` (folha — forest green)
  - Secondary: `#8b6914` (terra — bronze)
  - Background: `#f5f0e8` (areia — sand)
  - Card: `#faf6ef`
  - Border: `#c8b48e`
  - Headline font: `Playfair Display`
  - Body font: `Inter`
- [ ] Custom CSS class `quilombo-theme` with these tokens

## Content Import

- [ ] Pull production DB: `flyctl ssh sftp get -a quilombo-araucaria /app/data/quilombo.db`
- [ ] One-shot importer in Rust: `co-web/src/bin/import_quilombo.rs`
  - Reads quilombo SQLite
  - Maps tables → Co entries:
    - `publicacoes` → `type: post` entries (markdown body, frontmatter: titulo, slug, autor, data, tags)
    - `eventos` → `type: event` entries (frontmatter: data, hora, local)
    - `missoes` → `type: mission` entries (frontmatter: status, objetivo)
    - `usuarios` → metadata only (count exposed, profiles not imported)
  - Decompresses zlib-compressed `corpo` field if needed
  - Writes to `data/universes/quilomboaraucaria/` and `entries` table
- [ ] CLI command: `co-web import-quilombo --src /path/to/quilombo.db`

## Backend Stats Endpoint

- [ ] `GET /api/v1/universes/quilomboaraucaria/stats` returns:
  - `totalUsuarios` (count from quilombo)
  - `totalPublicacoes`, `totalEventos`, `totalMissoes`
  - `versaoApp` (quilombo-blog version)
  - `ultimaSync` (last import timestamp)

## Sync Strategy

- [ ] Manual: re-run importer when content changes
- [ ] Future: webhook from quilombo-blog to trigger Co re-import (out of scope for MVP)

## UI Components

- [ ] Reuse quilombo-blog component patterns (cards, tags, hero) — port the CSS classes into a `quilombo-components.css` file
- [ ] Loaded only when universe theme is `quilombo`

## Acceptance

- [ ] Universe `quilomboaraucaria` accessible at `/co/quilomboaraucaria`
- [ ] Content visible (posts, events, missions) with quilombo branding
- [ ] Stats endpoint returns real numbers
- [ ] Import is idempotent (re-running doesn't duplicate)
- [ ] `cargo test` passes
