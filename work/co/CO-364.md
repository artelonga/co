## As
Yuri studying open-source projects for integration planning

## I Need
Two upstream OSS repos to appear as read-only CO universes so I can browse their docs, changelogs, and architecture inside the same SPA as my own content.

## So That
- I can read `[[claude-code::CHANGELOG.md]]` alongside CO's own changelog in one view.
- The graph view (CO-345) can show typed relations between my universes and these references.
- Future Scope-B work (issues/PRs ingest) has a foundation universe to attach to.

## Context

Two repos confirmed (2026-06-05):
- **odysseus** by `pewdiepie-archdaemon` — 54k stars, Python, "Self-hosted AI workspace", branch `dev`
- **claude-code** by `anthropics` — 130k stars, Python, agentic coding CLI, branch `main`

Both reuse the CO-337 remote-sync pattern: DB row + `remote_url` + `content_subdirs` → 15-min background sync pulls source content + CHANGELOG.

## Design

Mirror CO-347's seed.rs pattern. Two DB rows added to the admin-content seed array + two backfill UPDATEs to set `remote_url`.

`content_subdirs = ["docs", "README.md", "CHANGELOG.md"]` — only the public-facing surface we care to mirror, not the entire source tree (would balloon storage).

`visibility = public-subscribable` so anonymous visitors can browse without an account.

`parent_key = NULL` (top-level; not nested under another universe).

No code changes in routes, UI, or sync workers — the existing CO-337 worker picks these up on next boot.

## Acceptance

- [x] `odysseus` row exists in `universes` with `remote_url = https://github.com/pewdiepie-archdaemon/odysseus`, `remote_ref = "dev"`
- [x] `claude-code` row exists with `remote_url = https://github.com/anthropics/claude-code`, `remote_ref = "main"`
- [x] `content_subdirs` limits the sync to docs + top-level READMEs/CHANGELOGs
- [x] Boot backfill is idempotent (`WHERE remote_url IS NULL`)
- [x] Both visible at `https://co-artelonga.fly.dev/api/v1/universes/{odysseus,claude-code}` after deploy
- [x] CO-337 background worker clones them within 15 min of first boot

## Blast radius

- ~20 lines in `co-web/src/storage/seed.rs`
- No migrations, no new routes, no new tests required (CO-347's test coverage applies)
- Storage: ~30 MB per repo content (docs + CHANGELOG only)
