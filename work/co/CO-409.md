## Findings deferred from the #196 review (merge was blocked only on the fatal ones)

Efficiency:
- graph lens re-fetches the full multi-universe graph on EVERY renderContent
  (incl. every search keystroke) — cache per universes-set + invalidate on switch
- `#search-input` has no debounce — full innerHTML rebuild per keystroke
  (kanban/table too, not just graph)
- `refreshTasks`: `getTasks` + `getDevTasks` awaited sequentially — Promise.all
- `maybeOpenEntryFromUrl`: up to 6 path candidates as serialized 404 round
  trips — parallelize or go straight to the `?q=` resolver
- boot path serializes `loadMeUniverses` before `bootAppForUniverse`

Reuse / dead code:
- ~250 lines copied from variant a's app.js (URL routing, boot decision tree,
  bindStaticEvents) — extract to a/modules and import, like the rest
- graph lens: hand-rolled fallback + wrong co_graph API shape — integrate the
  CO-335 primitive properly (load `/variants/a/lib/co-graph.js`, correct opts)
  + typeColor() duplicates shared/graph.html's TYPE_COLORS palette
- document-assets.js/document-tree.js are copies of conteudo.js internals the
  document lens never executes — delete or truly extract
- style.css: most selectors match nothing the JS emits (`.co-form-field` vs
  emitted `form-field`, `.co-graph-container` vs `graph-lens-container`) —
  reconcile naming so the intended styles actually apply
- modules/form/test.js: console harness shipped to the prod static dir,
  imported by nothing — move under e2e/ or delete

Registry generalization (skip if CO-387 already did it):
- computeDynamicTabs hardcodes gantt as the only multi-named-view lens type —
  generalize named manifest views for any lens
- lens contract lacks toolbar/deactivate hooks — switchView hardcodes
  timeline's zoom/nav chrome

Dropped variant-a behaviors (restore or consciously drop):
- mobile header overflow menu (CO-358), conversas trigger + unread badge,
  readme/license/feedback deep links (CO-264/CO-333), no-projects toast
  (2.7.29), langchange re-render of injected tabs
