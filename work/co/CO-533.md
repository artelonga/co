GIVEN the agent's synthesis loop (and the lead/research digest) needs **recent,
multi-source context distilled into one coherent summary** — and
`mvanhorn/last30days-skill` already pulls Reddit / X / YouTube / Hacker News /
Polymarket and folds them into a single summary — and CO-503 lets any OSS enter as
a manifest while `.claude/skills` is the dev-agent layer,
WHEN we land recent-research synthesis (compose > new code; manifest > binary),
THEN last30days enters as a CO-503 **manifest** tool the agent runtime calls AND as a
`.claude` **skill** for the dev agent — one source distilled into one summary, feeding
the synthesis loop / lead digest, with no product-code rewrite.

## Acceptance

- [ ] **Manifest add-on.** last30days is a `tool_type: predictive` manifest under
  `tools.d/` (`url`, `input_schema: { topic, sources?, window_days? }` → a coherent
  multi-source summary) — **no CO binary recompile** (CO-503 + CO-523 HTTP invoker).
- [ ] **Multi-source → one summary.** It fans across Reddit / X / YouTube / Hacker
  News / Polymarket and returns a single coherent summary (sources cited), not raw
  feeds.
- [ ] **Also a `.claude` skill.** The same capability is exposed as a `.claude/skills`
  entry for the dev agent (research/digest), per the registry's `skill` classification.
- [ ] **Feeds the synthesis loop / lead digest.** The agent runtime (CO-504) invokes it
  in-loop to ground a synthesis or build a leads/research digest.
- [ ] **Opt-in, degrades gracefully.** Registered only with external tools enabled
  (`CO_ENABLE_EXTERNAL_TOOLS=1` + trusted dir, CO-523); per-source/API absence yields a
  partial summary or unavailable tool, never a crash. Source API keys flow only via
  `secrets:`.
- [ ] CHANGELOG-PENDING/CO-533.md.

## Notes
- Enters as a **manifest + skill, not a binary rewrite** — the CO-503 composability
  pattern (drop a manifest / skill, the agent calls it). Two surfaces, one capability.
