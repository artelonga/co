## As

A maintainer of `co-web`

## I Need

A Playwright e2e spec that asserts every critical static-asset URL returns the **correct `Content-Type`** AND that the anonymous SPA bootstrap **actually completes** (sidebar populated, no JS console errors)

## So That

The 5-version regression cascade we just walked through (2.13.3 → 2.13.4 → 2.13.5, each fixing the previous fix) cannot happen silently. A single failed CI check on MIME type would have caught CO-232's `serve_deep_link` intercepting `/variants/a/app.js` and serving HTML.

## Context

- **Why now**: CO-232's `serve_deep_link` matched `/{slug}/{*subpath}` which also matches `/variants/a/app.js`, `/shared/i18n.js`, `/pdfjs/build/pdf.js`. The browser refused to execute HTML-typed scripts → no SPA bootstrap → every "Carregando..." stuck forever.
- **What no existing test covered**: routing tests asserted *paths* but not *response Content-Types* on those paths. The deep-link spec checked `/<universe>/<entry>` returns 200, but not what's *in* the body or its MIME.
- **Scope**:
  - New file: `co-web/e2e/static-assets.spec.ts`
  - Assert `Content-Type` matches expected MIME for each entry in a hardcoded list:
    | Path                                | Expected Content-Type           |
    |-------------------------------------|---------------------------------|
    | `/variants/a/app.js`                | `application/javascript`        |
    | `/variants/a/modules/api.js`        | `application/javascript`        |
    | `/variants/a/modules/sidebar.js`    | `application/javascript`        |
    | `/variants/a/modules/boot.js`       | `application/javascript`        |
    | `/variants/a/style.css`             | `text/css`                      |
    | `/shared/i18n.js`                   | `application/javascript`        |
    | `/shared/markdown.js`               | `application/javascript`        |
    | `/shared/production.css`            | `text/css`                      |
    | `/shared/experiment.css`            | `text/css`                      |
    | `/pdfjs/build/pdf.js`               | `application/javascript`        |
    | `/manifest.json`                    | `application/json`              |
    | `/sw.js`                            | `application/javascript`        |
  - Each row: hit with `request.head()` or `request.get()`, assert status 200 + content-type prefix match (case-insensitive).
- **Bonus** (same file or sibling spec `co-web/e2e/anonymous-bootstrap.spec.ts`):
  - Open `/` in incognito context, wait for `state.userUniverses` to be populated (via `page.evaluate(() => window.__co_state?.userUniverses?.length)` — expose this in a debug build or check via DOM presence).
  - Assert: sidebar shows at least 1 universe item, board shows at least 1 task, no console errors during boot.

## Acceptance

- `static-assets.spec.ts` runs and asserts every path's MIME type.
- New CI step (or just `npx playwright test e2e/static-assets.spec.ts`) catches a regression that returns `text/html` for any JS/CSS asset.
- Anonymous bootstrap spec verifies the rendered DOM has populated content (not just an empty shell).
- Tests pass locally + against `BASE_URL=https://co.artelonga.com.br`.

## Blast radius

- ~100 LOC of test code, zero production code. Adds 12-15 quick HEAD/GET assertions per Playwright project run.
- Adds ~3-5s to CI total.
