## Premissa (owner steer 2026-06-13): ADITIVO, não breaking
A capacidade de sync é o diferenciador ("substituir git"), mas **não exige
breaking change agora**. É uma superfície NOVA, não uma troca: novas rotas, novo
`co sync` CLI, novos formatos que coexistem com o markdown canônico. Ship em
**MINORs aditivos** (v3.9, v3.10…), zero disrupção. O MAJOR fica no bolso para
quando *remover* os caminhos antigos for justificado — não para adicionar feature.

## Sequência aditiva (cada uma MINOR, coexiste com o que já funciona)
1. **CO-444** — Federation API (criar universo token-auth + visibility + convites
   + assinatura pública). Desbloqueia Yggdrasil (YG-126/138). Foundation.
2. **CO-70 / CO-63** — manifesto `_universe.yaml` + plugins de content-type
   (universos sem manifesto default; aditivo).
3. **CO-61** — Sync Protocol v1 (op-log + blobs content-addressed + 3-way) como
   ENDPOINTS novos + `co sync`. APIs HTTP/Vault atuais intocadas.
4. **CO-75** — reconstrução de versão (replay do op-log).
5. **CO-51 / CO-91** — `co sync` CLI (pull/push/watch).
6. **CO-54 / CO-128** — idempotência + UI de conflito (Apple-style 4-way).
7. **CO-96** — UI de CRUD de universo. **CO-88** — UAT do pipeline e2e.
8. **CO-86 / CO-87** — formato `.co` + protocol stack (transporte novo; markdown
   continua canônico).

## DEFERIDO — breaking, só num MAJOR futuro, gated em "novo path provado + adotado"
- **CO-90** — dropar o admin tier global (muda modelo de permissão).
- **CO-64** — remover o legacy `git_sync.rs`.
Não são necessários pra entregar sync; só quando *remover* o velho fizer sentido.

## Acceptance (epic)
- [ ] `co sync` pull/push/watch funciona contra um universo, com 3-way merge e
      reconstrução por timestamp — TUDO via rotas/CLI novas, sem mudar contrato
      existente (smoke do CO-421 verde antes/depois de cada release).
- [ ] Universos criados por usuário/serviço externo (CO-444) federam pro CO.
- [ ] Nenhuma das releases do épico é breaking (semver MINOR); o MAJOR de cleanup
      (CO-90/CO-64) fica separado e explicitamente adiado.
