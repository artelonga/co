GIVEN CO-61 (sync protocol v1) defines an op log of all entry mutations, and the manifest epic must support "show entry as of T" and auto-generated changelogs,
WHEN we add op replay infrastructure on top of the op log,
THEN any past state of any entry is queryable, and changelogs reconstruct from ops without manual maintenance.

## Architecture (depends on CO-61)

- Op log: append-only `(universe_key, entry_path, op_type, payload, parent_op, created_at, author)`
- Snapshots: at every Nth op or every M minutes, persist materialized entry state as a snapshot row
- Replay: to reconstruct entry at T, find latest snapshot before T, apply ops from snapshot.op_id+1 forward
- Auto-changelog: scan ops grouped by entry, summarize using manifest-declared rules (e.g., "status: todo → done = task completed")

## Tasks

- [ ] Snapshots table: `entry_snapshots(universe_key, entry_path, op_id, payload, created_at)` indexed
- [ ] Replay engine: reads ops, applies in order, returns entry state at given T
- [ ] API: `GET /api/v1/universes/:slug/entries/:path?as_of=<RFC3339>`
- [ ] Diff API: `GET .../entries/:path/diff?from=<T1>&to=<T2>` returns op-level diff
- [ ] Auto-changelog generator: aggregates ops, formats as Keep-a-Changelog
- [ ] Manifest hooks: content type may declare `changelog_summary: <template>` (e.g., "{title} marcado como {status}")

## Scale notes

- Snapshot every 100 ops bounds replay cost: O(100) op applications per query worst case
- Op log compaction: at 1B ops per universe, partition by month + cold-tier oldest months to S3 (CO-81)
- Replay is read-only — runs on read replicas (CO-77)
- Changelog generation is a job, not request-blocking (CO-78)
- For entries with millions of ops (rare), consider per-entry compaction passes

## Acceptance

- Entry state at T matches what was written at T (verify against test ops)
- Diff between T1 and T2 shows only changes in that interval
- Changelog for a universe over 6 months generates in < 30s for 100K entries
- Replay scales linearly in ops count; snapshots prevent unbounded replay
