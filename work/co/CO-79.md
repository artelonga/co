GIVEN every request loads the universe manifest (CO-70), `theme.css` is computed per request, and read-heavy workloads dominate, with no shared cache today,
WHEN we add an in-process LRU for manifests + Redis for query cache + CDN headers for static assets,
THEN hot reads serve from cache (< 1ms), reducing DB load by 80%+.

## Architecture

| Layer                 | What                                  | TTL                           |
|-----------------------|---------------------------------------|-------------------------------|
| L1 (in-process LRU)   | Manifest, schema, parsed config       | 5 min, invalidated on write   |
| L2 (Redis)            | Query results, theme.css, views       | 60s, key includes content hash|
| CDN (Fly Edge / CF)   | Static assets, theme.css              | 60s, NOT immutable            |

## Tasks

- [ ] In-process LRU using `lru` crate, capped at 10K entries per cache type
- [ ] Manifest cache: invalidate on `PUT /api/v1/universes/:slug` and on manifest update
- [ ] Query cache (Redis): wrap hot read paths with key = SHA256(query + universe_key + manifest_hash)
- [ ] `theme.css` endpoint: short Cache-Control (60s) + ETag for conditional requests; **no `immutable`**
- [ ] Cache invalidation: pub/sub on universe-update event triggers L1 + L2 invalidation across workers
- [ ] Metrics: cache hit rate per layer, eviction rate

## Scale notes

- L1 LRU at 10K entries × ~100 KB = 1 GB max — fits in worker memory
- Redis ops ~100µs; a cache hit replaces a 5-50ms DB query — 50× speedup
- CDN at 1M req/sec is free for static; `theme.css` must be cacheable at the edge
- Cache stampede protection: singleflight on cache miss (only one request fills cache)
- CSS/JS short cache (60s), never `immutable` — no hashed filenames yet

## Acceptance

- Repeat manifest read serves from L1 in < 1ms (microbenchmark)
- `theme.css` cache hit rate > 95% at CDN edge after warmup
- Cache invalidation propagates < 1s across worker processes
- Stampede test: 1000 concurrent cache-miss requests result in 1 DB query
