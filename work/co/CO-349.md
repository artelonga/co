### `_universe.yaml` skeleton (every folder, identical shape)

```yaml
name: "<Category> (<Language>)"
description: "<one-line placeholder; refine per-universe later>"
version: 0
content_types: []           # intentionally empty; schemas in follow-up tickets
properties: {}              # placeholder; per-universe spec adds these
```

### Stub `.md` files

```markdown
---
id: 1
name: "Placeholder NPC 1"
status: stub
---
```

(Same shape per category; content_type field omitted intentionally so the universe loader uses the parent default.)

### Helper script

Add /Users/artelonga/projects/yggdrasil/scripts/scaffold-content.sh that creates the tree above. Idempotent: skips folders/files that already exist. Run once, commit the result.

```sh
#!/usr/bin/env bash
set -euo pipefail
ROOT="$(dirname "$0")/../content"
declare -A COUNTS=( [npc]=15 [monster]=15 [location]=10 [item]=10 [faction]=5 [encounter]=5 )
for category in "${!COUNTS[@]}"; do
  count="${COUNTS[$category]}"
  for lang in "" shandara tagmar godot; do
    dir="$ROOT/$category${lang:+/$lang}"
    mkdir -p "$dir"
    [ -f "$dir/_universe.yaml" ] || cat > "$dir/_universe.yaml" <<EOF
name: "${category^} ${lang:+($lang)}"
description: "Placeholder universe — schema TBD."
version: 0
content_types: []
properties: {}
EOF
  done
  for i in $(seq 1 "$count"); do
    f="$ROOT/$category/$i.md"
    [ -f "$f" ] || printf '%s\n' "---" "id: $i" "name: \"Placeholder $category $i\"" "status: stub" "---" > "$f"
  done
done
```

### Wiring to CO prod

After this PR merges in yggdrasil and CO-347 lands yggdrasil's `remote_url` in CO seed, the 15-min sync clones the yggdrasil repo and walks `content/`. With `content_subdirs: ["content"]`, each sub-folder with a `_universe.yaml` becomes a sub-universe of `yggdrasil` in CO. CO-337's existing parent_key resolution already handles the nesting; no CO-side code change required.

### What this ticket does NOT do

- Define properties schemas per category (NPC needs `race, class, faction, …`; monster needs `cr, hp, attacks, …`; etc.). Each schema is a separate per-universe ticket and can be authored in parallel after this scaffold lands.
- Migrate real content from Shandara/Tagmar sources. The 60+ stub markdowns are placeholders — they exist only to give CO something to count.
