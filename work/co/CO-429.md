## As
Launcher/agente operando sobre o CO, QUERO o repo do Claude Code registrado
como universo subscrito e um catálogo navegável das superfícies de integração
(CLAUDE.md, skills, hooks, headless flags, output formats), PARA que qualquer
sessão consulte a referência canônica on-demand em vez de carregar esse
conhecimento no contexto de cada launch.

## Escopo

### 1. Universo `claude-code`
- [ ] Importar `anthropics/claude-code` via `co source add` (adapter CO-417,
      pós-fixes CO-423) como universo `claude-code`, `parent: co`,
      privado inicialmente. Importar docs/ e exemplos — NÃO o código-fonte
      inteiro (filtro de paths no source; sem binários).
- [ ] Registro 100% via DB/API (PUT/source add) — nenhum mapeamento
      universo→repo em Rust (regra do projeto).
- [ ] `index.md` de entrada (o adapter pós-CO-423 garante) apontando para os
      docs mais úteis a launchers: headless/output-format, hooks, settings,
      CLAUDE.md/memory, skills.
- [ ] Re-sync funciona (rodar `co source sync` duas vezes é idempotente).

### 2. Catálogo de tools integráveis
- [ ] No universo `co`, criar entradas `tools/claude-code/<superficie>.md`
      seguindo o schema de tools (`tools/schema.yaml`) — uma por superfície:
      `headless-stream-json`, `model-flag`, `claude-md`, `skills`, `hooks`,
      `session-jsonl`, `otel-telemetry`. Cada uma: o que é, quando o CO usa
      (link para a task do epic que a consome), exemplo mínimo, link
      `claude-code::<path>` para o doc canônico no universo importado.
- [ ] Links cross-universe na sintaxe canônica `key::path` (storage) /
      `[[key::path]]` (corpo markdown).
- [ ] `co universe digest claude-code` (CO-428) lista o universo com o
      catálogo visível nos modelos/contagens.

## Acceptance Criteria (gerais)
- [ ] `GET /api/v1/universes/claude-code` → key, parent, contagens corretas.
- [ ] Catálogo validado por `co validate all` (schema de tools respeitado).
- [ ] Nada de MCP: o catálogo documenta superfícies CLI/arquivo/API apenas
      (decisão de projeto 2026-05-04).
