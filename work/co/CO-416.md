## As
Miguel, QUERO que o conteúdo do meu universo apareça em pt-br **e** en
automaticamente, PARA alcançar leitores nos dois idiomas sem traduzir à mão.

## Distinção importante
A UI já é i18n (pt/en via `setLang`). Esta story é tradução de **conteúdo**
(corpo markdown das entradas), que hoje NÃO existe.

## Acceptance Criteria
- Uma entrada com `lang: pt` pode gerar uma tradução `lang: en` (e vice-versa)
  sob demanda, preservando frontmatter, estrutura markdown, code-blocks e
  wikilinks (não traduzir código nem `[[key::path]]`).
- Provider plugável (`CO_TRANSLATE_BACKEND`): default no-op/manual; backend
  LLM (reusa a infra de IA existente) atrás de env. 503/aviso quando ausente.
- A tradução é uma **entrada irmã** rastreável à original (`translated_from`),
  não sobrescreve; re-traduzir é idempotente por hash do corpo-fonte.
- Toggle de idioma na UI mostra a tradução quando existe; senão, oferece gerar.
- Teste: round-trip preserva wikilinks + code-blocks.

## Acceptance
- [x] Entrada `lang: pt` gera tradução `lang: en` (e vice-versa) sob demanda via
      `POST /api/v1/universes/{slug}/translate/{*path}?to=en` (owner-gated).
- [x] Preserva frontmatter, estrutura markdown, code-blocks e wikilinks
      (`[[key::path]]`) — masking por sentinelas antes do backend; teste
      `preserves_code_blocks_inline_code_and_wikilinks` + `build_twin_preserves_structure`.
- [x] Provider plugável `CO_TRANSLATE_BACKEND`: default no-op → **503** gracioso;
      `llm` reusa `infra::ai::AiRouter` (sem novo cliente LLM).
- [x] Twin é entrada irmã rastreável (`translated_from` + relação tipada CO-74),
      não sobrescreve; re-traduzir é idempotente por `translated_from_hash`.
- [x] Toggle de idioma tem dados para consultar: `GET .../translation/{*path}`
      retorna `exists`, `path`, `lang`, `stale` (UI completa = follow-up).
- [x] Teste round-trip preserva wikilinks + code-blocks (MUST-PASS) + idempotência.
- [x] `cargo fmt` / `cargo clippy -p co-web -D warnings` limpos; `cargo test -p co-web`
      verde (1399 testes, +14 novos); rota no api-catalog + openapi regen/check limpo.

## Notas
co-auto-runnable. Escopo de provider real fica atrás de `CO_TRANSLATE_BACKEND=llm`
para a primeira entrega ser segura (default = manual/503). Sem migração: a
proveniência vive em frontmatter + `entry_relations` (CO-74).
