GIVEN voice is a capability the agent runtime (CO-504) should call like any other
tool — and `jamiepine/voicebox` is a self-hostable STT/TTS service that runs
**entirely on one box with no cloud STT/TTS and no API bill** — and the canonical
tool contract (CO-503) already covers predictive HTTP add-ons (yt-summarizer,
rag-service),
WHEN we land voice composition (compose > new code; manifest > binary),
THEN voicebox enters as a `tool_type: predictive` **manifest** under `tools.d/`
pointing at a running voicebox service — a thin client of the agent runtime, no
binary rewrite — landing the voice goal of CO-522 as a real external add-on.

## Acceptance

- [ ] **Manifest, not code.** voicebox is added as a single `tool_type: predictive`
  manifest (`url`, `input_schema: { action: transcribe|synthesize, audio_b64?, text?,
  voice? }`) dropped into the trusted `tools.d/` catalog — **no CO binary recompile**
  (CO-503 contract, CO-523 HTTP invoker).
- [ ] **Local-first, no API bill.** The default path uses a **self-hosted voicebox**
  backend; audio/text never leave the instance and no cloud STT/TTS is called
  (aligns with the CO-497 data-residency invariant). The real voicebox backend is
  injected/configured, not embedded.
- [ ] **Thin client of the runtime.** The agent (CO-504) invokes `transcribe` /
  `synthesize` through the canonical tool-calling loop exactly like any other tool —
  voice is not special-cased.
- [ ] **Lands CO-522's voice goal** as a concrete external add-on; voicebox is the
  reference voice tool alongside the predictive HTTP shape of yt-summarizer/rag-service.
- [ ] **Opt-in, degrades gracefully.** Registered only when external tools are enabled
  (`CO_ENABLE_EXTERNAL_TOOLS=1` + trusted dir, CO-523); an absent service makes the
  tool unavailable, never a crash.
- [ ] **Reviewable sample.** A runnable, offline, stdlib-only stub under
  `examples/integrations/voicebox/` (manifest + `service.py` + README), indexed and
  exercised by `scripts/review-integrations.sh`.

## Notes
- Enters as a **manifest/technique, not a binary rewrite** — the whole point of the
  CO-503 composability engine: drop a manifest, flip `status: active`, the agent calls it.
- Cross-refs: **lands CO-522** (voice-transcribe / local-only STT-TTS goal); calls the
  CO-504 runtime; same adapter shape as CO-525 (rag-service). NOT MCP
  (`feedback_no_mcp.md`) — plain HTTP behind the native external-tool adapter.
- Registry: `ArteLonga/docs/TOOL-REVIEW.md` catalogues **voicebox → P5** (this task);
  OpenMontage (video) is catalogued for later.
- Term is **tool/ferramenta** and **agent/agente** — never "bot".
