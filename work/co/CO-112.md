## As

a CO operator running an alpha cohort

## I Need

a co-agent **adapter trait** with a Fly-sidecar reference implementation, A/B-testing primitives on the existing OLTP, and a documented quota/tier model

## To

ship A/B testing and structured telemetry **before** the streaming bus is justified — using OLTP + WAE as the cheap interim — and lock in the agent abstraction so subsequent phases just add adapter variants

## Stories

- CO-120 — Co-agent adapter trait + Fly sidecar reference impl
- CO-121 — A/B primitives on OLTP (`feature_flags`, `ab_assignments`, `ab_exposures`)
- CO-122 — Quota/tier model spec (no enforcement yet)

## Acceptance gates

- [ ] `trait CoAgent { fn ship(&self, events: &[Event]) -> Result<()> }` lives in `co-core` with Fly-sidecar impl
- [ ] An assigned A/B variant for a given (`user_id`, `flag_key`) is **stable across reads** for the holdback duration
- [ ] Quota/tier doc reviewed and merged; no enforcement code yet
- [ ] One end-to-end A/B exposure event visible in WAE within 60s

## Out of scope

- Streaming bus (Redpanda) — Phase 3
- Quota enforcement code (CO-80) — Phase 2
- Cloudflare Worker / Vercel adapter variants — Phase 2

## Why now

A/B and telemetry primitives are a week of work on existing OLTP. SR plan parked them at Phase 2 (streaming bus). Don't wait — build cheap, replace later.
