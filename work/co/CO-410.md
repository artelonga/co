## GIVEN / WHEN / THEN

- GIVEN the sala at `/u/{universe}/sala`, WHEN it loads, THEN the canvas is a
  **natural landscape**: an infinite grid over deterministic procedural
  terrain (água/margem/campo/mata/terra/rocha — value noise, no assets), with
  faint grid lines and the origin square subtly marked. A brand-new sala is
  seeded with the root pasta `/` at the origin.
- GIVEN a logged-in user, WHEN they click an empty square, THEN an inline
  editor opens on that square and typing commits by content:
  - **single character** → the character renders on the square (grid-as-text);
    Enter/Tab advances to the next square so letters flow seamlessly
  - **`/nome`** → a **pasta** (folder unit) on that square
  - **longer text** → a **nota** card on that square
  - **empty** → clears the square
- GIVEN notas and pastas on the landscape, WHEN the user drags them (pointer
  events — mouse and touch), THEN they move with a ghost + snap preview and
  drop snapped to the grid; occupied squares spill to the nearest free square.
- GIVEN a nota dragged onto a pasta, WHEN dropped, THEN it **joins the
  pasta** (badge count increments); the pasta drags as one unit with its
  members; the pasta panel lists members and clicking one pops it back out.
- GIVEN an anonymous visitor, WHEN they view the sala, THEN it is read-only:
  pan/zoom and item panels work, edit gestures raise the login CTA
  (e2e contract of CO-352 preserved — verified by Playwright smoke).
- Layout JSON v2 (`cells`/`notes`/`folders` + legacy `nodes`/`edges`/`view`)
  persists via the same `workspace_states` PUT; v1 graph layouts migrate to
  notas on load (node id = entry_path so edges keep resolving).

## Context

User feedback 2026-06-11: click-and-drag on the CO-352 graph canvas did not
work, and the sala should read as a "default filled map" the user types onto,
not an empty void. The co-graph.js force-graph renderer was replaced (in
sala.html only — graph.html still uses co-graph.js) by a self-contained grid
engine with dirty-flag rendering. Verified end-to-end with a headless
Chromium smoke test (12 assertions: editor flow, persistence shape, drag into
folder, folder-unit drag, anon CTA).
