GIVEN the design mocks (mock/code.html for Scholarly Automaton, mock/code 2.html for Relic Archive) define high-end editorial aesthetics with tonal layering, glassmorphism, Newsreader typography, and Material Icons, and the current board UI is plain vanilla CSS that doesn't match,
WHEN I align the board CSS and HTML with the mock design systems,
THEN:

## Typography

- [ ] Load Newsreader (serif, headlines/body), Work Sans (sans, labels) for Scholarly theme
- [ ] Load Newsreader (serif, headlines), Manrope (sans, body/labels) for Relic theme
- [ ] Google Fonts `<link>` injected by theme engine based on active preset
- [ ] Headline hierarchy: project name = `text-3xl font-headline`, task titles = `text-lg font-headline`, labels = `text-xs font-label uppercase tracking-widest`
- [ ] Body text: `font-body` for descriptions, comments, content

## Surface & Depth (from DESIGN.md)

- [ ] **No-Line Rule**: Remove all `1px solid` borders between sections. Use background tonal shifts instead (`surface` → `surface-container-low` → `surface-container`)
- [ ] Sidebar: `surface-container-low` background, no right border — depth via color shift
- [ ] Cards: `surface-container-lowest` on `surface-container` background — "lifted parchment" effect
- [ ] Kanban columns: background shift per column, no borders between columns
- [ ] **Ghost borders**: Where accessibility requires edges, use `outline-variant` at 15% opacity
- [ ] **Ambient shadows**: Modals get `0 20px 50px rgba(0,0,0,0.15)` — expansive, warm-tinted
- [ ] **Glassmorphism**: Floating menus/tooltips use `backdrop-filter: blur(20px)` with `surface-bright` at 80% opacity

## Color Tokens (extend theme_engine.rs)

- [ ] Scholarly presets: full Material Design 3 token set from mock/code.html tailwind config
  - `surface: #FFF9ED`, `primary: #8E4E00`, `primary-container: #CD7F32`, `secondary: #8C4F10`, `tertiary: #805533`, `on-surface: #1D1C15`, etc.
- [ ] Relic presets: full token set from mock/code 2.html tailwind config
  - `surface: #131313`, `primary: #FFB3B5`, `secondary: #E9C349`, `on-primary-container: #E0505F`, `surface-container: #201F1F`, etc.
- [ ] All tokens mapped to CSS custom properties: `--md-primary`, `--md-surface`, `--md-on-surface`, etc.
- [ ] Dark companion for Scholarly: invert surface tiers, keep warm brass tones
- [ ] Light companion for Relic: warm rose-tinted light version

## Components (from DESIGN.md)

### Buttons
- [ ] Primary: `primary-container` bg (#CD7F32 for Scholarly, gradient for Relic), subtle inner glow
- [ ] Secondary: transparent bg, ghost border (15% opacity), hover increases to 40%
- [ ] Tertiary: text-only, Newsreader italic with underline on hover

### Cards (Kanban task cards)
- [ ] No dividers between cards — whitespace separation
- [ ] Asymmetric padding (more left than right) for editorial feel
- [ ] Subtle hover: background shift to `surface-container-high`
- [ ] Priority indicator: thin left border with priority color (not a pill)
- [ ] Status badges: pill-shaped, `primary-container` bg for Relic, tonal shift for Scholarly

### Sidebar
- [ ] Follow mock: full-height, warm tonal background, nav items with icon + Newsreader labels
- [ ] Active item: accent bg at 20% + border highlight
- [ ] Hover: translate-x shift (subtle pull) instead of background change
- [ ] Project list: clean, no chevrons, collapsible by section

### Header
- [ ] Sticky, glassmorphism (gradient bg + blur), subtle shadow
- [ ] Project name: large Newsreader headline, not truncated
- [ ] View tabs: rounded pill group, active tab gets accent bg
- [ ] Search: bottom-border only (ledger style), focus transitions to primary color

### Input Fields (from mocks)
