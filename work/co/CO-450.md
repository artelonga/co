## Contexto
O Yggdrasil (YG-138, lado deles, shipping em v2.29.0) tem um botão **🌐 Criar no CO**
(owner-only) que redireciona ao CO **autenticado** com prefill. O CO precisa de um
handler de deep-link `?criar` que abre o modal de criar-universo (CO-96) já
preenchido e cria via `POST /api/v1/universes` (CO-444). Até este handler aterrissar,
o botão do YG degrada gracioso (abre o CO sem prefill).

## Contrato do deep-link (ACORDADO 2026-06-14 — CO adota os nomes do YG)
`https://co.artelonga.com.br/?criar=1&name=<nome>&key=<chave>&source=yggdrasil&instance=<id>`

| Param | Significado | Uso no CO |
|---|---|---|
| `criar` | trigger (`1`/truthy) | abre o modal de criação no load |
| `name` | nome do universo (prefill) | preenche `#criar-name` |
| `key` | chave sugerida (lowercase/hífen) | preenche `#criar-slug` (validação CO-96 aplica) |
| `source` | proveniência (`yggdrasil`) | telemetria `universe_created {source}` + tag opcional |
| `instance` | id da instância Yggdrasil | proveniência/linkage (telemetria; v1 não cria parent) |

> **Nota ao agente do Yggdrasil:** o CO usa **exatamente** esses nomes — **nenhuma
> mudança no `criarNoCO()`** é necessária. Se vocês mudarem algum nome, me avisem.

## Acceptance
- [ ] SPA (variant-a) lê `?criar=1` no boot; se presente, abre o modal CO-96
      (`openCriarModal`) **pré-preenchido** com `name` e `key` do query.
- [ ] **Auth-aware:** se não logado, dispara o fluxo de login e **retoma** o prefill
      após autenticar (o botão do YG já manda "autenticado", mas cobrir o caso de
      sessão expirada). Não vazar prefill pra usuário errado.
- [ ] Submit cria via `POST /api/v1/universes` (CO-444) com os campos do modal; em
      sucesso, redirect pro `/co/<key>` (comportamento atual do CO-96).
- [ ] Telemetria: evento `universe_created` carrega `source` + `instance` quando vierem
      do deep-link (mede conversão da federação YG→CO).
- [ ] Limpar os params da URL após consumir (history.replaceState) pra não re-disparar
      no refresh.
- [ ] `key`/`name` inválidos → modal abre com o erro inline do CO-96 (não cria às cegas).
- [ ] Teste e2e: visitar `/?criar=1&name=Foo&key=foo-bar&source=yggdrasil` → modal
      abre preenchido; (logado) submit cria + redireciona.
- [ ] Sem migração; sem mexer no backend (reusa CO-444 + CO-96).

## So that
Fecha o round-trip vivo YG-126/YG-138 ↔ CO-444: "criar universo" no Yggdrasil vira um
universo federado no CO em um clique, com proveniência medida.

## Não no escopo
- Criar `parent_key` automático a partir de `instance` (linkage forte) — follow-up.
- Convites/subscribe no fluxo de criação (CO-444 já tem as rotas; UI fica pra depois).
