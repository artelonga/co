## As

A user looking at the storage dashboard or universe overview

## I Need

A real lines/words/chars count of all .md content per universe, separate from `content_count` (file count)

## So That

I see at a glance how much *content* my universe holds, not just how many files it has — and the dashboard never mislabels 'Entradas' as 'lines'.

## Context

- **Principles:** §3 (static typing — metrics named for what they measure), §6 (data fields encapsulate one meaning)
- **Scope:** Add three new columns to `entries`:

```sql
ALTER TABLE entries ADD COLUMN body_lines INTEGER NOT NULL DEFAULT 0;
ALTER TABLE entries ADD COLUMN body_words INTEGER NOT NULL DEFAULT 0;
ALTER TABLE entries ADD COLUMN body_chars INTEGER NOT NULL DEFAULT 0;
```

Compute on insert/update in vault PUT handler:
- `lines = body.lines().count()`
- `words = body.split_whitespace().count()`
- `chars = body.chars().count()`

Aggregate per-universe in the dashboard response:
```rust
pub struct UniverseStats {
    pub content_count: i64,    // existing
    pub md_bytes: u64,         // existing
    pub body_lines: i64,       // new
    pub body_words: i64,       // new
    pub body_chars: i64,       // new
    ...
}
```

Update `co-web/static/shared/storage.html` to surface the new fields. NEVER use the label 'lines' for `content_count` — label that field as 'Entradas' / 'Entries' uniformly.

Migration: a one-time backfill pass on boot that walks the entries table and computes the three counts for rows with DEFAULT 0 values. Idempotent — re-running is a no-op.

## Acceptance

- Migration adds the three columns.
- Vault PUT writes the three counts on every insert/update.
- `/api/v1/admin/storage` returns non-zero `body_lines` aggregates per universe.
- The storage HTML page shows 'Entradas / Linhas / Palavras / Tamanho' columns distinctly.
- Audit script: `grep -r '"lines"' co-web/static` returns nothing where `content_count` is rendered.

## Blast radius

Medium — schema migration + UI labels. Backfill is bounded by total entries (~7000 across all universes today).
