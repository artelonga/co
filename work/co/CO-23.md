GIVEN anonymous users can create universes and content (CO-21, CO-22),
WHEN an anonymous universe reaches 100 content entries,
THEN:

- [ ] Middleware `check_usage_gate`: on every write operation (POST task, POST comment, POST project), count current entries for the universe
- [ ] Entry count = tasks + comments + projects in the universe's scope
- [ ] `universes.content_count` column updated on each write (increment) and delete (decrement) — avoid COUNT(*) on every request
- [ ] If content_count >= 100 AND universe.owner_id IS NULL (anonymous):
  - Return 402 Payment Required with JSON: `{ "error": "usage_limit", "message": "Crie uma conta para continuar", "message_en": "Create an account to continue", "current": N, "limit": 100 }`
- [ ] If content_count >= 100 AND universe.owner_id IS NOT NULL (logged in):
  - Allow write (no limit for authenticated users)
- [ ] Frontend: on 402 response, show modal prompting account creation
  - "Você atingiu 100 entradas. Crie uma conta gratuita para continuar."
  - "You've reached 100 entries. Create a free account to continue."
  - Buttons: "Criar conta" → /auth/register, "Entrar" → /auth/login
- [ ] After login/register: link anonymous universe to user account (set owner_id, match by co_universe_owner cookie)
- [ ] Universe claim: `POST /api/v1/universes/:slug/claim` — authenticated user claims an anonymous universe (cookie must match)
- [ ] Content count displayed in universe header: "42 / 100 entradas" (anonymous) or "42 entradas" (logged in)
- [ ] Unit test: create 99 entries OK, 100th OK, 101st blocked for anonymous, unblocked after login
- [ ] `cargo test` passes, `cargo clippy -- -D warnings` clean
