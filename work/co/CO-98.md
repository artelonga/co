GIVEN universes today are a flat list and there's no way to express that the timeline trio (`tempo`, `humanity`, `universo`) is logically a subset under `template`, AND the user reported "lots of Meu Co" clutter combined with "we want timeline universes added under template category",
WHEN we add a `parent_key` column on `universes` and surface it in the sidebar as collapsible parent → children groups,
THEN content-curated universes can be organized hierarchically without inventing a separate "category" abstraction, and the SPA's universe browsing surface stays scannable as the trio (and future trios) grow.

## Data model

Add to the `universes` table:

```sql
ALTER TABLE universes ADD COLUMN parent_key TEXT NULL;
CREATE INDEX idx_universes_parent_key ON universes(parent_key);
```

- Nullable — top-level universes have no parent.
- No FK constraint — universes can be deleted independently of their children. If a parent disappears, children become top-level (rendered as orphans → fine UX).
- `seed_timeline_universe` accepts an optional `parent_key` field in the manifest; the three timeline JSONs set `parent_key: "template"`.

## API

`GET /api/v1/universes` includes `parent_key` in each row. Listing stays flat — the SPA does the tree-build client-side. Avoids ordering ambiguities and keeps the API simple.

`GET /api/v1/universes/:slug` includes `parent_key`.

`PUT /api/v1/universes/:slug` accepts `parent_key` in the body (owner only). Setting to null detaches.

## SPA behaviour

`renderSidebar` builds a tree from the flat list:
- Top-level universes render as today.
- Children render under their parent with a 16px left indent and a small chevron (▾ / ▸).
- Parent's expansion state persists in `localStorage` under `co_universe_tree_<parent_key>`.
- Default: parent expanded if any child is the currently active universe; otherwise collapsed.

On the **template's home page** (`renderUniverseHome` for the template), the empty-state hint is replaced by an `Explorar` panel listing direct children:

```
Explorar este universo:
  • Tempo — Onde tudo se encaixa
  • Universo — Linha do tempo cósmica
  • Humanidade — História da nossa espécie
```

Each card links to `/co/<slug>`.

## Out of scope

- Multi-level nesting beyond depth 2 (defer until needed).
- Categories as a separate concept (parent_key suffices).
- `parent_key` change propagation in the UI on edit (refresh fixes it for now).
- Permissions inheritance from parent (a future ticket — child currently has its own owner_id and visibility).
