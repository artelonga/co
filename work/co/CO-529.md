GIVEN comunicacao is currently a yggdrasil-internal corpus read from a
`../comunicacao` sibling dir, so its meaning-topology content is reachable only by
the game and not by co or co agents,
WHEN we promote comunicacao to a first-class **co universe** — content stays
canonical markdown in its own repo (`artelonga/comunicacao`), and co subscribes to
and reads it like any other universe,
THEN co and agents (and the bot, via the universe) can consume comunicacao through
the normal subscription path, while the writeback contribution flow is preserved.

## Acceptance

- [ ] **comunicacao is a subscribable co universe.** It registers as a universe
  (key `comunicacao`) that co + agents can subscribe to and read via the standard
  universe API — no yggdrasil, no sibling-dir read.
- [ ] **Content stays canonical markdown in its own repo.** The source of truth
  remains `artelonga/comunicacao` (markdown). co subscribes/reads; it does not fork
  or duplicate the content into the CO seed (honors the no-cross-repo-seed rule).
- [ ] **Writeback contribution flow preserved.** Contributions back to comunicacao
  (edits / new entries) continue to work through the existing writeback path; the
  promotion does not break the contribution loop.
- [ ] **Decoupled from yggdrasil.** yggdrasil consumes comunicacao as a subscribed
  universe (or via the CO-528 topology tool/artifact), not via `COMUNICACAO_DIR`.

## Notes
- Stakeholder↔project / subscription pattern: comunicacao becomes a public-subscribable
  content universe (sibling to `topologia`), consistent with `project_universe_is_repo`
  (universe = any local folder, git repo is optional backing) and the
  no-hardcoded-universe→repo-mappings rule (store the mapping in DB, not in Rust).
- Pairs with CO-528: CO-529 makes the *content* canonical + subscribable; CO-528 makes
  the *topology* a portable CO-503 tool/artifact. Both remove the `../comunicacao`
  sibling-dir coupling.
- Sacred corpora (Ayvu Rapytã / Ifá) keep their sovereignty/CARE gate at the content
  layer too — custodian-controlled visibility, not auto-published.
