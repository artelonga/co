GIVEN turning external media (YouTube talks) into first-class, connected,
publishable knowledge in a CO universe was ad-hoc, and the prior art was a single
stub card (`mbya/refs/youtube-*.md`),
WHEN we provide a documented, repeatable pipeline — create universe → `referencias/`
folder → ingest videos as reference cards (transcript + metadata + connection
links) → author a synthesis doc → publish a Quartz static site,
THEN any universe can absorb video references with transcripts and a connection
graph, and publish like grcsamazonia/miguel, with markdown staying canonical.

## Acceptance

- [ ] `scripts/ingest-youtube-reference.sh <url> <out-dir>` produces a `reference`
  card: yt-dlp metadata + description + top comments + bestaudio → Whisper
  transcript → `youtube-<id>.md` with the transcript embedded and substantive
  description links lifted into `connections:` (store/tracking links filtered).
- [ ] The card mirrors the mbya/refs YouTube reference format (type: reference,
  medium: video, platform: youtube, video_id, url, channel, tags, connections).
- [ ] `docs/pipelines/youtube-reference.md` documents the full e2e flow incl.
  prerequisites (yt-dlp, ffmpeg, whisper venv, redearte) and the gated deploy.
- [ ] Worked example delivered: the **agroecologia** universe (`~/projects/agroecologia`)
  — `_universe.yaml`, a synthesis doc (*Raízes Pensantes*, pt-BR, for
  agroecologists, on the plant-behavior/consciousness/neurobiology debate), two
  reference cards (the two requested videos), built to a Quartz static site
  (`public/`, title *Raízes Pensantes*).
- [ ] Raw artifacts (`_ingest/` audio + venv, `public/`) gitignored — not canonical.

## Out of scope / follow-ups

- Shipping a `referencias/` scaffold + the reference card format in the CO
  template (so every new universe gets it).
- Wiring the `connections:` frontmatter into the CO-74 relation graph on ingest
  (currently a frontmatter list; relation rows are created on vault write).
- Deploying the agroecologia Quartz site to Fly (gated — needs a Fly app + approval).
