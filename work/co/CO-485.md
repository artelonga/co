GIVEN a user is seeded once with the ~90 MB bundle (CO-484), re-shipping it daily
would be wasteful, and CO is already event-sourced (`op_log`/`event_log`/
`replay_state`, CO-95),
WHEN a client syncs daily by pulling only the **op_log delta since its cursor**
per universe and applying engine updates via **binary diffs** (bsdiff/zstd),
THEN steady-state cost is ~KB–MB/user/day for content and single-digit MB only on
an engine release — cheap enough to give every user the whole platform.

## Acceptance

- [ ] Content delta: `GET /{slug}/op_log?since=<cursor>` returns events after the
  cursor (build on `op_log_routes` / CO-95); client applies via `replay_state`.
  Idempotent + resumable; returns the new cursor.
- [ ] **License re-check on sync:** a universe that flipped to private/proprietary
  stops syncing to clients (gate by `data_class`/`visibility`).
- [ ] Binary update: signed `co self-update` fetches a **bsdiff/zstd patch**
  (old→new engine), verifies signature + checksum, atomically swaps the binary.
- [ ] Conflict handling reuses `sync_conflicts`; offline-tolerant.
- [ ] Bandwidth per sync is logged + a `/metrics` counter; documented budget.
- [ ] Docs: `docs/distribution/sync.md`.

## Out of scope / follow-ups

- The bundle exporter (seed) → **CO-484**.
- P2P / mesh sync between users (future).
- A scheduled client daemon (launchd/cron) — reference the local-host kit.
