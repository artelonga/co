# Co — Gestão de conteúdo em grafo

**Co** é uma plataforma para criar, organizar e compartilhar conhecimento em universos colaborativos. Cada arquivo é um nó; cada conexão, uma aresta. O conjunto forma um grafo vivo de ideias.

Você está no **universo template** — o ponto de partida. É aqui que novos usuários começam a explorar o Co antes de criar o próprio universo.

## O que é um universo?

Um universo é um espaço de conteúdo: uma pasta de arquivos `.md` com metadados YAML, indexados em SQLite para busca rápida. Pode ser um blog pessoal, o painel de uma equipe, um jardim de conhecimento ou um portfólio.

Universos **públicos** são descobríveis por qualquer pessoa. Universos **privados** são visíveis apenas para você e os colaboradores que você convida. Leia mais sobre as opções de visibilidade em [Privacidade](/privacidade).
