# CO — Plataforma de código aberto

**CO** é o software livre que roda esta plataforma. Tudo que você usa aqui — o quadro Kanban, o jardim de conhecimento, a linha do tempo, o editor colaborativo — é desenvolvido abertamente neste universo.

O código vive em [github.com/artelonga/co](https://github.com/artelonga/co) e cada tarefa de desenvolvimento está registrada aqui como CO-N.

## O que você encontra neste universo

- **Quadro de tarefas** — as CO-N tasks ativas, desde bugs até grandes funcionalidades. Cada card é um arquivo `.md` com critérios de aceitação, contexto e histórico de decisão.
- **Documentação técnica** — arquitetura, segurança, infraestrutura e integrações.
- **Roadmap** — o que foi feito, o que está em progresso e o que vem a seguir.

## Documentação

- [Changelog](/changelog) — histórico de versões com filtros por tipo, tamanho de PR e intervalo.
- [Segurança](/seguranca) — modelo de ameaças, criptografia e cenários de ataque.
- [Infraestrutura](/infra) — deploy, backups, CDN e observabilidade.
- [Renderers](/renderers) — Mermaid, CodeMirror, PDF e outros.
- [Licença](/licensa) — AGPL-3.0.

## Como contribuir

1. Leia uma tarefa CO-N no quadro acima.
2. Abra um issue ou PR no repositório.
3. Ou [crie sua conta](/), fork este universo e proponha mudanças diretamente.

→ **[Universo template](/template)** — o ponto de partida para novos usuários.
