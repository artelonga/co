GIVEN every content entity in CO should be represented as a markdown file on disk,
WHEN the server starts or an entry is modified,
THEN SQLite is updated as a read-optimised index of the filesystem state.

## Implemented

- [x] `entries` table (path, universe_key, entry_type, title, frontmatter_json, body, body_hash)
- [x] entries_fts (FTS5 full-text search)
- [x] Migration v12/v13 — migrate old projects/tasks → entries
- [x] Entry CRUD API at `/api/v1/universes/{key}/entries`
