Editor de posts integrado ao painel admin.

## Entregue

- CRUD completo em /admin/posts (criar, editar, excluir)
- Auto-geracao de slug a partir do titulo
- Preview de markdown (renderiza via marked no servidor)
- Upload de imagens com insercao automatica de markdown
- Toggle rascunho/publicado
- Drafts protegidos: acesso direto por URL bloqueado para nao-admin
- Log de atividade para cada operacao
